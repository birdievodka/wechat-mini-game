# 桃园小英雄 · 全音频试听方案 01

更新：用户要求直接在游戏里试听，已按[音频接入v9.3](audio-integration-v93.md)制作运行版本。以下保留原始试听设计，实际分事件音效、音乐编码和验证以接入说明为准。入口为 `art/audio/review-v1/index.html`，可直接用浏览器打开；单播放器避免同时点播叠音。清单与来源在同目录 `manifest.json`。

## 音乐方向

不是幼儿儿歌、庙会庆典或沉重的影视史诗。以少年游侠的轻巧和战场推进感为主：短木质弹拨、少量笛答句、低战鼓和克制短弓弦。旋律留空给战斗反馈，不靠唢呐、尖笛或大镲吸引注意。

| 场景 | 候选 | 结构与听感 |
| --- | --- | --- |
| 备战／选人 | 桃园小聚 | 96 BPM，16小节40秒；大调五声色彩、暖弹拨、轻木扣，稀疏笛答句。轻松但不过分欢快。 |
| 正式战斗 | 少年出阵 | 128 BPM，32小节60秒；相同动机转小调五声色彩，战鼓与短弓弦推进，问答和低音区变奏避免循环疲劳。 |
| 首领战候选 | 阵前争锋 | 128 BPM，16小节30秒；战斗曲同速同调变奏，鼓句更密、音区下沉，响度与普通战斗相近。 |

三首均为原创编排与离线合成音色，**不是民乐实录，也不是调用音乐生成模型的输出**。本轮音色和音乐方向供审核；不把工程合成自动等同于正式发行母带。无外部音乐采样、无模仿指定曲目。合成只能说明来源，不等于自动完成版权登记或平台审核。

商店继续保持战斗音乐；备战曲不在购物时突然切入。正式接入时需保留用户手势解锁、音乐/音效独立开关、后台暂停和前台续播。场景切换建议0.6–0.9秒交叉淡化，需审核通过后实现，本轮没有改变播放状态机。

除草鞋只有命中声，其他类别均提供出手／命中。物理升级以节奏、出手次数和重音变化为主，不随品质无限变响。单个挥击、爆炸、分裂、穿透不得按受击人数叠声。未来接入三连，本命第三击可选重刃强调，但不能再叠同一击的普通命中和暴击。

## 技能与敌军

12通用技能逐一提供候选，详情可在试听室技能栏听：百步穿杨八次弦扣，横扫六合金刃厚斩，八门金锁木令玉锁，火烧连营线状燃起，水淹七军浪头浪沫，星落五丈原五段星坠，背水一战短出阵鼓，护体剑阵四剑起阵，震军号令两沉鼓加共鸣，雷霆万钧四雷递进，万箭齐发四轮箭束，以及冲锋破阵的蹬地枪击。

持续增益期间不循环响；护体剑阵只在生成、命中或成功挡击时发声。技能候选是按完整招式时序合成的试听，**实际接入必须拆成真实出招/命中事件**，不能提前播放命中、取消攻击后仍响、重新叠放整段。技能充能仍15真实普通兵，没有数值修改。

七Boss共21招分别提供候选，名称对应boss-roster/lvbu-boss。蓄力提示与释放分工：统一危险双敲、骑兵蓄势三拍；张角电裂低雷，吕布蹄鼓与重戟，董卓印击/铜钱/酒火，袁绍束弩，曹操银刃纸影，孟获猪蹄/狼爪/象踏节奏，司马懿棋落与星鸣。怪群不逐只脚步、不逐只喊叫。这里的兽群采用合成地面接触音，没有宣称录制了真实动物。

全40兵按实际木器、金属、弓弩、火器、法术材质共用武器类别，加近战出招、射手放箭、器械后坐、冲锋预警、同批出生提示。仍需实现真实调用路由；不是说40兵已经加载这些新声音。

## 反馈、界面与清晰度

- 主角受伤独立钝击，优先级最高，不再用草鞋样本冒充；格挡与受伤互斥。
- 普通受击、倒下、暴击、铜钱、回血、技能就绪、冲刺、坐骑蹄步、少年脚步均有素材。普通受击是专用武器命中的回退，暴击替换普通命中，不双响。
- UI覆盖点击、选英雄、装备、购买、卖出、刷新、升阶合成、余额不足、打开、关闭、出阵、波末、Boss到场、胜利、失败、解锁。
- 不增加大段语音。失败为温柔下行，配哭脸，避免嘲讽式滑音。

建议接入混音约束（本轮为离线试听规则，**尚未写入运行代码**）：

| 声部 | 规则 |
| --- | --- |
| 关键反馈 | 主角受伤／格挡、迫近危险优先4；技能／Boss招式／界面优先3。不能被机关枪挤掉。 |
| 普通攻击 | 实际命中优先2，敌方出手1，普通出手/环境0；同时最多6个效果声道，另有音乐声道。 |
| 限频与合并 | 普通命中同类90–140ms；高频火器约140ms；金币120ms合并；普通死亡250ms；出生按批350ms。准确值在manifest候选配置中。 |
| 音量关系 | 出手通常低于命中；受伤最高但不削波。技能/危急提示让音乐短降约5–6dB、约220ms恢复；普通攻击不反复压音乐。 |
| 空间 | 普通敌声只近场，远处/画外衰减；不为画外80兵逐个发声。主角低音量脚步在密集场景可省略。 |
| 大招 | 技能大招与Boss大招同帧时保留危险预警和主角受伤，装饰性尾音可让出声道。 |

两段混音分别演示备战/购物22秒和密集战斗28秒，属于**离线示意而非Cocos实录**。本轮混音夹具按六声道和同音限频筛事件；未来接入还需实现关键声抢占、空间衰减与状态取消。不能把候选manifest说成现有运行机制。

## 来源、资源和审核

`scripts/render-audio-review.py` 固定随机种子，依赖NumPy/SciPy与macOS afconvert。音乐音序存同目录music/*-score.json，无损音乐母带在ignored local/audio-review-masters，可由脚本重建，不重复纳入运行包。试听AAC128kbps、音效PCM16/24k单声道。新文件仅在art下，微信包体积增加为0。保留当前候选，不累积旧试听版本。

草鞋逐字节复制现有资源，原始来源为用户指定爱给网素材。保留这一来源标记；这次不对其商业授权作额外保证，也不改变原文件。

本轮验证92段WAV/AAC可解码、时长、文件哈希、36武器/12技能/21首领招式覆盖、生成片段端点/电平、试听页单播放器切换/搜索/窄屏。新合成音频无满幅削波；既有草鞋原样本0dBFS、98个接近满幅样点，按用户已确认音源原样保留，单独记录，不将其谎报成新合成的低峰值片段。音乐无损循环边界为零差值；AAC提供试听，接入前仍须真实引擎/手机测试循环与响度。验证数据见候选目录validation.json与browser-validation.json；没有声称完成主观听感或iOS真机验收。

审核时优先判断：备战曲耐听程度、战斗曲战斗感、三首是否同世界；木器/刀剑/火器是否有分辨度；主角受伤与敌方危险是否突出；是否有刺耳/过长/太电子的声音。通过后再按类别调音量、接真实事件、验证iOS解码内存和播放并发，构建微信体验。
