# v9.20 无尽模式商店峰值治理

2026-11-19，iPhone15ProMax无尽约2–3分钟整微信退出。此轮修复明确的额外图形占用及UI/Boss准备重叠；尚无Jetsam/微信系统崩溃记录，未确认手机唯一终止原因。

## 改动

- 同一BattleSpriteAtlas从70格/4.5MiB扩展到87格/5.5MiB，商店卡片、品质底条、玉绿面板、遮罩、品质菱形、徽标及包子复用Sprite，保持文本和交互。没有新增下载图片/额外2048²图集。
- 无尽继续按钮先销毁商店UI再准备下一Boss；金币、商品购买与装备仍在Run，失败沿原重试/返回流程。
- 前台商店也每5秒采样本地故障快照，增加mode/tier/Boss图集/frameScope。没有每帧存储或新音频源。
- 音乐播放失败恢复限制为同曲两次（5秒/30秒），只额外刷新一次临时文件；超额停止该曲自动重试，换曲/明确重开/手动开启恢复。同曲无尽补给不能刷新额度。不能确认手机当时发生过音乐错误，但消除了持续重载路径。
- 敌军/弹体/危险区/技能及原生7声音源预算不变，不调低敌密度/伤害/特效。
