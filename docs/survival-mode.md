# 桃园乱斗：两关无限生存 v2.6

2026-11-12 实现。正式开局固定五颗心，20秒热身后进入无限关。此前八关流程退出正式入口。

## 游戏循环

选英雄并点开始，携带角色默认武器 → 20秒步兵热身 → 自动回收金币、军饷30、回满五心 → 热身补给购物（可全买及刷新） → 点击“进入无尽”后原地提示“难度升级” → 无限关。没有额外赠送武器，新增武器必须购买。

无限关只计算前台实际模拟时间。30秒一次补给，90秒节点替代为大强化。每屏三张卡均可购买，各卡每屏限购一次，已购后仍可刷新并继续买；每次补给刷新费为5、8、11、14……金币，金币不足不能刷新且不涨价，下次补给重置。货比三家仅优惠每次补给的第一次刷新。大强化可放弃并切换普通补给寻找恢复。购买后保持暂停，点“继续战斗”后有1.2秒冻结准备及受击保护，随后8秒降低新敌投入，不重置场上敌人、弹丸、技能或冷却。暂停、补给、准备和后台不计成绩。

90秒节点出现两只强化骑兵，180秒节点出现张角。精英/首领占用正常出兵预算，存活张角不重复生成。场上80敌上限、同时2骑兵冲锋、4远程兵蓄力。

## 生存与成长

- 固定五颗心。任何攻击一次扣一心，1.2秒全局受击无敌；普通敌人被推开，已开始冲锋的骑兵保持轨迹。
- 不存在生命上限成长、护甲减伤、自动再生或吸血。热乎肉包付费回复一心，正式战斗时间每60秒限购一次，满心不会售卖。
- 每级经验需求为 `10 + 5*(等级-1)`；升级不弹面板，伤害加3个百分点，最高30级，满级后每10经验转一金币。
- 六武器位。早期供应普通武器，120秒后可能出现精良武器。满六格时可出现指定装备升阶，或新武器的指定替换，不自动丢武器。补给中可免费合成相同装备，或回收非最后一件。
- 60种被动道具与9种大强化；草鞋弹射、绿豆扇形豆雨、桃枝击杀次生爆炸均已接入攻击。次生效果禁止递归，桃花爆炸有0.12秒全局触发间隔。极晚期池耗尽后回退为三种收益递减的基础修炼。
- 心与桃子靠近后自动拾取，满五心也消耗掉落物但不继续加血；未满心每个回复一心。
- 吸金基础范围240，刘备另有15%，最高360。被吸附金币持续追踪，补给前自动回收。

## 曲线与经济

以无限关分钟m计，步兵生命 `24 * 1.28^min(m,8) * 1.35^max(m-8,0)`，入场时确定，不追溯修改已有敌人。其他兵种使用相同生命倍率；速度缓慢增长至上限130，张角上限70，伤害永远一心。

每秒预算 `min(7.5,2.5*1.16^m)`，步兵/远程/骑兵/张角权重1/1.25/2.5/20。到敌数上限时丢弃新增普通出兵，不积攒爆发队列。补给后8秒出兵间隔乘1.8。

基础价格 `min(80,round(28*1.035^补给序号))`。武器品质系数1/1.6/2.5/4，恢复1.8，大强化1.5—2。每30秒固定军饷12，掉落1/2/4/32金币；经济强化用小数余数累积，避免低额收入加成被取整吞掉。

低收入时保底一张最高12金币的基础攻击卡。恢复、武器专属增益、大强化按当前构筑适配，不出现未持有武器的专属强化。购买验证金币、资格、槽位、已购状态，不允许重复结算。
