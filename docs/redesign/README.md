# 《桃园小英雄》全量重制设计

2026-11-24 · 美术与武器规则设计 · 概念评审版

当前采用新版首页、选关、补给和结算界面，以及武器、技能的新设计。英雄、普通兵、首领与战斗地表沿用经典 Q 版资产。下文人物与场景重绘作为早期设计资料。当前运行范围见[实装与验收](implementation.md)。

以桃园营地、小刘／小关／小张、黄巾农兵和暗黑张角为美术基准。全游戏换成有块面体积的二维手办风，保留搞笑三国的身份。英雄小而俏，杂兵靠装具见招，Boss 用沉色、宽肩和专属兵器形成压迫感。亮色优先用于操作反馈、真实命中与必须读到的预警。

## 美术规范

| 对象 | 造型和配色 | 在手机上先看见什么 |
| --- | --- | --- |
| 刘关张 | 约 1.3–1.4 头身，圆头、短袍、低五官、圆拳。奶白与玉绿打底，角色各留一组强调色 | 发型和头饰 → 武器 → 小表情 |
| 普通兵 | 同一手办比例，五官和衣边更简练。军巾、甲片用阵营色，装备按材质区分 | 镰刀、盾、弓弩、马兽、器械、符纸中的一个主形状 |
| 精英与 Boss | 精英在所属单位轮廓上增一件有身份的部件。Boss 约 1.7–2.0 头身，宽窄各异，少量高冠、暗袍、旧铜及锋边 | 成人面部、轮廓质量、主兵器。危险提示仍单独取光 |
| 武器与道具 | 剪影优先，旧木、粗陶、冷铁、竹、红绳各一主材质。轮廓暖棕，最多三块主要明暗。品级主要放在角标和托底 | 器物本身的形状及当前品质 |
| 场景 | 低剪影密度的手绘地面配边缘微缩景物。暖灰接地、低对比草纹、少量颜色边缘 | 角色脚下、可走区域、危险边界 |
| 界面 | 深玉绿底、米白纸托、旧金窄边。主动作暖金，破坏性操作朱砂。数字与中文正文可独立排版 | 主操作、当前状态、次级入口 |

共用色样以墨棕 `#342821` 描边、玉绿 `#315A50` 做 UI 基底、暖米白 `#F4E5CA` 做面板、蜂蜜黄 `#E7AE54` 做主操作、烟紫 `#332A42` 做 Boss 阴影。友方刃尖可用暖白或青白，敌方可伤边界固定为伴随断口、方向或倒计节奏的高对比朱铜边。战斗内避免压暗全场，暗黑质感集中在 Boss 本体与登场短镜头。

人物交付以正/侧/背动作注册图为准，手、腰、脚接地点与图标裁格独立。粗轮廓在手机缩放下保留一条连续对比线。武器柄有握点、投射物有尖/尾方向、坐骑与器械有明确地面接点。画面验证直接对照实际相机，可视重叠、轮廓与动势优先于全身立绘细节。

横屏概念以 16:9 构图，实装样板以现行 1440×750 视口和微信实际安全区复核。主角、沙盘和前排攻击区域随可用宽度排布。角落装饰按边缘裁，主按钮、头像栏、摇杆、技能和首领判定信息按安全区锚定。小图标至少复核等比例缩到 32px 时的轮廓，深浅地面各测一次。关名、价格、伤害数值和角色名独立排版。

## 六关场景

六关各制作同构的四样资产，包括首页微缩沙盘、无字缩略图、可镜像拼接的战地底、外围小物。主控地面保留宽阔负空间，低反差图案不指示障碍。沙盘幢影和边缘陈设可以更立体，战斗相机下地形接点和安全区以程序为准。水岸、城墙、竹影等装饰通过构图留在边缘。

| 关卡 | 沙盘焦点 | 战斗地表、边缘与 Boss 光色 |
| --- | --- | --- |
| 黄巾起义 | 草甸土路、木寨、黄旗、两座布帐 | 春草暖黄低反差，边缘桃枝与矮栅。张角用旧金对墨紫。敌雷预警用清楚的固定符圈 |
| 虎牢讨董 | 高门、砖墙缺口、斜坡与暗红军旗 | 温赭夯土配少量灰石。吕布赤兔、董卓铜印均能与地面分开，砖块不进入走位中心 |
| 官渡争锋 | 粮车、芦苇、低粮仓、营道 | 收割后黄灰平原与烟蓝阴影。箭簇、弩车横臂、箭墙缺口在相近亮度下仍靠形状辨认 |
| 赤壁鏖兵 | 暗红石岸、船尾、栈桥与粗绳 | 冷蓝灰碎石和暖赤坡岸，近色火场靠亮锋和短时纹理区分。银锋与纸人不混成一团 |
| 南中平蛮 | 竹林、藤石门、青灰岩台 | 湿润灰绿空地，深色植被集中于边。象、狼、猪不同重心和步点可见，避免大块树冠遮人 |
| 五丈原决战 | 夜靛层丘、浅灰石台与低灯 | 灰靛平地，棋盘只在实招出现。黑白双龙轮廓不贴地消失，陨石预警使用局部浅边 |

## 制作与验收

1. 先用黄巾起义做整条样板。首页沙盘 → 草鞋与黄巾农兵 → 横扫六合与张角 → 第一场补给 → 结算。正背动作、站位清晰度和图标缩小一并验收。
2. 兵器原型只画四件，并行用真实规则验证站桩和主动走位的差异。结果通过后按共用触发类型铺齐 33 件，再更新正式商店和图鉴提示。
3. 逐关补环境、兵种与 Boss。在同一 Cocos 机位查看起手、出招、命中、收招，压测六槽、敌方预警与多目标重合。和现版采用同一种子、同类阵容、同分辨率进行比较。
4. 运行资源沿既有分包与动态释放。核心首屏优先，后续 Boss、宠物、按需界面使用相应资源组织。地图共享图集与镜像规则沿用。特效共享绘制、固定池和既有声音通路。现有 80 敌、80 敌方移动物、160 友弹、280 粒子、6 危险区与真机包线进入后续验收。
5. 实装阶段再验证普通、无尽、演武的规则一致性、旧存档资格与迁移、场景切换和失败重试。对微信包和手机实测分开记录，手机覆盖六槽高负荷、十分钟无尽、反复进店与切后台。

制作交接记录每个 ID 对应的原图、裁格、朝向、接地和持握锚点、阴影、需要单独控制的部件与打包入口。多关并行或同类共用时仍保持同一材质基线和对象注册。缺失资源按已有加载边界处理。优先检查三组容易混淆的画面，包括玉绿英雄站在南中深绿地面、朱色危险圈叠在赤壁火场、五丈原的墨色首领进入靛色地表。
