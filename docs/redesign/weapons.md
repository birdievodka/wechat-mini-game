# 武器系统重制规则

[重制总览](README.md) · [33 件逐件四档成长稿](../weapon-system-redesign.md) · [四件武器概念板](../../art/concepts/taoyuan-redesign/weapon-prototypes.png)

六槽自动攻击。每件武器首先回答「我走到哪里，它就更好用」，再回答「这一阶伤害多多少」。轻兵器的收益是腾出半步，长兵器造出安全距离，箭弩靠队列，法术和器械靠引敌通过指定地点。红 IV 的强招由读得懂的战场条件触发。

## 品质与购买

| 品质 | 购买承诺 | 共用信息 |
| --- | --- | --- |
| 白 I | 立即获得招牌动作，单件上手就有可用战法 | 器物剪影、基本伤害、间隔、作用范围与该兵器的主要短板 |
| 蓝 II | 降低一个使用难点，如折返提速、连击更易接上、箭穿过多一人 | 清楚展示哪一步更快、更长或更稳 |
| 紫 III | 改变走位收益，如动态回手、外圈起势、两点连区 | 显示推荐站位和触发条件，说明有效路径或区域 |
| 红 IV | 达到明确人数、顺序或时机才打出高光 | 显示触发与每轮上限。尚缺几人或几击只在相应武器反馈处短显 |

- 从当前 33 件、30 件可获得及 3 件预留出发。初始三基础武器、三个本命 ID、正式／无尽／演武目录、已有资格映射沿用。青莲飞剑、龙胆银枪、古锭刀仍预留，设计四级行为以便日后启用。
- 商店在当前四货位中呈现普通购买、同兵器升阶、消耗品和被动，刷新、支出、旧投资退还、免费本命及首次奖励都使用已有规则。首轮样板不同时调经济，保持现有起始币和商店时机，以便对照。
- 同一 `uid` 的升阶只进下一档。对于实际升阶或替换，要在一次确认前核验品级、金钱、货架、资格、选择槽及退款，以免重复购买和显示失真。卡片关闭后回到原商店状态。
- 每件武器以 128×128 设计画板画本体轮廓。四档共用辨识剪影，强调色只加在功能改变处，譬如手戟折返铜环、贯石弩箍、火油壶封泥。图标、手持和飞行保留同一握点与武器尖，品级可用形状和罗马字同时读。
- 商店同时显示当前数值和升级后动作。「白 I：回到出手处」「紫 III：回到你手里」可以连起来读。卡片描述要从实际规则取值，至少给伤害、间隔、作用范围、条件和主要限制。替换预览显示失去的能力、真实投资可退金额与本次净额。本命三连用单独一行和角标。

## 击序与上限

1. 本轮用该槽出手时的品质、增益、伤害与武器 ID 建立一次出手。新玩法的次数、条件和伤害基准从本轮出手取值。D 表示该槽在出手时包含品质及被动后的单击伤害。表中倍率只乘一次。独立状态绑定槽位 `uid` 与本轮波次/场景身份。
2. 单敌的本轮去重基于出生代次。旧目标节点复用后按新对象判断。追踪、回程、飞行、陷阱命中由现有物理和战斗时间驱动。只有确认命中才增加红品计数、出对应火花及声音。空挥只表现起手与收手。
3. 红 IV 每个本轮最多触发一次，其追加攻击带来源标记、不能计入自己的触发。持续类另以一次部署为轮。同目标同一持续时段的共享上限按现有同类资源规则执行。控制效果由重敌或首领抗性折算，首领不得被条件奖励无界牵引或打断。
4. 卖出/替换停止新追加，已释放的独立弹道和场地沿用既有寿命，过期收回。持续贴身的武器组或器械按装备移除的生命周期关停。升阶后下一轮生效，已在途实例持原品质快照。购物、暂停、后台冻结状态。跨关、死亡重试、退出演武清理本轮与累计。
5. 本命三连仍看专属标记与实际成长。专属第三击按本命入口，普通红品条件沿各自槽结算。同一第三击若也满足红品条件，合并视觉并按单轮预算裁抑重复反馈，全部实体命中与叠加上限在样板回归时单独查。
6. 多段受击暴击与击退只按实际命中的规则记账。原有被动、递减与适配上限继续作为起测条件。通用全局品级倍率与新的额外段不重复叠伤，对空挥或掉帧不补发伤害。六槽自动兵器不消耗主动技能 15 击杀充能。

## 33 件触发判据

四档招式、可用走位及反馈见[逐件成长稿](../weapon-system-redesign.md)。下表规定消歧及终止条件。所写计数按同轮/同部署解释。跨轮才有意积累的兵器另写归零。硬性危险边界必须从真实碰撞、时钟和目标读取。

| 兵器 | 上线规格中的计数、追加和边界 |
| --- | --- |
| 草鞋 | 首命中与连续弹射必须是不同敌人，末跳推开是红 IV 完成第三跳才有的反馈。被动增加弹跳仍受总上限 |
| 扁担 | 梢击以最后约四分之一竹担有效半径识别。红 IV 当次梢击命中三敌才让末敌踉跄，单敌一轮只受一次横扫 |
| 杀猪尖刀 | 紫／红追踪连续已命中的同一敌，换目标、空刀或槽位撤出归零。破绽仅自己的下一刀可消费 |
| 双股剑 | 左、右剑分别记命中，以同一敌两侧相会成立交叉口。下一轮合刃消费一次，不借另一槽完成 |
| 青龙偃月刀 | 上一次回正后实际沿地移动积累拖刀长度，站桩不积累。红 IV 同轮刀腹击中三敌向末敌前方递出单短锋 |
| 丈八蛇矛 | 枪尖带与枪杆分开，回挑只由真实枪尖击中开启。最佳距离命中精英才触发红品一次点地 |
| 方天画戟 | 勾和主扫各记一次，首领只受减弱牵引。红 IV 两名不同普通兵确实被勾入才补一次短戟背 |
| 龙胆银枪 | 第三刺允许按真实走向重定。三刺各命中且落在三个独立方向扇区才回马，追加不再计方向 |
| 青釭剑 | 盾类判定从真实防御来源获取，裂口只由实际破盾产生。同敌裂口消耗后进入本敌短间隔 |
| 倚天剑 | 计数按主剑实际出手，第四次产生主月牙，红品三次不同穿透才在末端展半月。已经被该月牙击中的敌人不再受半月 |
| 七星宝刀 | 星位按实际刀击积累，命中精英的增速仍受整刀单次积星限制。满星一次全部消费，每敌同轮至多一份收拢伤害 |
| 古锭刀 | 换目标才推进不同敌人序号，连续三个才解锁正前重斩。原地刷同一目标不能充满 |
| 双铁戟 | 同轮首拍、次拍共享夹击判据。红品只在两拍命中同一敌的交汇处触发一次，单拍正常收 |
| 三尖刀 | 两翼必须各命中不同敌军才出中锋短斩。每敌本轮最多计一次分翼，触发只追加一次 |

| 七星灯 | 七个灯位借外缘有效擦击依次点亮，亮满后消费并旋出一圈。同一灯轮同敌一次 |

| 武器、现行对照 | 新四档方案 | 买前怎么说 | 可验证站位 |
| --- | --- | --- | --- |

## 画面和声音

- 草鞋只用黄织面一拍压扁和短拍声，击中才挠一下对手衣摆。扁担木杆有小幅弯直。尖刀用局部白锋。基础武器的强度来自身体与接触。
- 区分转向、穿透、落地和区域持续。五雷符细枝沿实敌跳。雷霆万钧同拍垂直落下。火油壶地面局部红洼与窄火线。火烧连营沿固定大火线滚动。贯石弩单矢走长线。万箭齐发的箭来自高处批次。
- 同类接触效果在同一目标 80ms 内可合并视觉，伤害独立结算。重击姿态停顿 35–55ms 只影响武器表现。真实受伤与危险信号优先占用六声道。多箭一发一声、多次真实命中用低一点的节拍，展示追加只在真实生成后响。

## 比较与验收

固定同英雄、同档、相同兵器投资及种子，分别测 30 秒孤敌、8 人纵列、12 人包围、移动首领。记录伤害、击退成功、实际命中不同敌、危险区暴露时间、退路长度与追加次数。各武器在至少一类场景进入同价组前列，同时保留一项接近 20% 可感得失的弱点，该比值是调参目标。

最低要通过白／蓝／紫／红四档、同档卖和替换、同名多件、更改本命标记、特殊攻击上限、六槽与多个持续区、暂停和场景清理。一轮噪声较大时记录同样种子的站桩、正确操作与故意失手三个结果。普通、无尽、演武要进入同一实际攻击、命中和回收路径。真机验收按照总览的运行阶段另做。
