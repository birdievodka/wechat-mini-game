# 技能、武器反馈与声音

[重制总览](README.md) · [技能轮廓板](../../art/concepts/taoyuan-redesign/skill-silhouettes.png)

每招用一个能读到的主体与一条主要节拍表达。人、己方动作、敌方预警和地面层分别可见。流程统一为起手、有效动作、真实接触、余波回收。具体空间锚点、判定次数、判伤与音效按各技能实际时钟。无命中时播放实际出手和余势。

12 个共享主动技正常开局就绪，使用后击杀 15 个真正普通兵恢复，达标至多蓄一发。演武使用自己的免充能设置。下文半径和时间是新美术对齐的当前行为。战斗重做表内单列待测武器规则。数据与逻辑有差异时以当前实际路径为准。

## 音色与保留优先级

备战旋律沿《桃园举旗》的明朗方向，重配为短铜管与木鼓质地。战斗和首领沿《全军出击》的推进节拍，暗色首领登场用单次低鼓、金器与角色音做重心，购物保持续播。音乐单源、六路 SFX、当前音频生命周期与首触逻辑进入后续实现验收。

| 材质／事件 | 声音 |
| --- | --- |
| 草鞋、木、竹 | 鞋底干拍、短木撞、竹条弯直，不使用法术尾音 |
| 刀枪戟、重盾与弩 | 小刃短嘶，重铁低碰。弩机开合与弦振分开。后坐不补第二次判伤声 |
| 火、水、风 | 火瓶陶壳破后才接火响。水有宽浪首沿与短流失。风/聚怪先收后放 |
| 雷、符和棋 | 己方同步四组落雷一次主雷声。敌雷预响与落雷分拍。纸符干响、棋石接触清脆，黑白双龙共用低高两种音色 |
| 受伤和危险 | 危险提示及玩家真实受伤优先，敌兵常规命中按类限频。短重复合并声音，不改变模拟时间 |

VFX 验收用同角度查看空放、单体、有多目标时的关键帧，分别查图层、声音、真实伤害和回收。保持友好主色和敌方预警的亮度区分，敌方实体超出视野时只处理现有边界行为。素材交接每招附原尺寸关键帧、方向、锚点、时间线和可以复现的玩法场景。
