# 手办风重制首批实装

首页、选关、补给和结算采用新版界面，英雄、普通兵、首领及相应头像采用原版美术。兵器和技能沿用现阶段已接入的新设计。移动端字体兼容修订自 `stage-v11.0.3-mobile-fonts` 接入。运行版本和实际画面见[验收记录](../../art/reviews/handcrafted/validation.json)。

首页「开始挑战」采用圆角切边、暖金内沿与深棕底座，文楷中黑叠加粗体。按压只移动按钮牌面，取消和松手均恢复。触控验证覆盖按下、取消和点击入关。

首页沙盘从六张插画的透明轮廓生成暖棕描边和左下软阴影。效果随原六格 `redesign-relief.png` 加载，留出透明间隔，保持沙盘、关名与城门的既有排版和选关交互。给 `capture-redesign-review.mjs` 设置 `TAOYUAN_RELIEF_REVIEW_DIR` 可在 Cocos 里额外截取六关首页近景。

界面字体使用霞鹜文楷 GB Lite v1.530 的 Regular 和 Medium 两个字重，随 `hero-menu` 本地分包加载，OFL 许可随字体保留。手机预览反馈仍显示系统字后，族名、唯一名、全名和 PostScript 名统一为 `TaoyuanWenkaiR1` 和 `TaoyuanWenkaiM1`，每个字重保留原裁剪字库、字形和度量。设置 → 运行诊断的「当前会话」记录实际选用的字库。Logo 仍为原图，战斗伤害数字仍走共享图集。[上游发布](https://github.com/lxgw/LxgwWenKaiGB-Lite/releases/tag/v1.530) · [Cocos 字体兼容记录](https://github.com/cocos/cocos-engine/issues/16799)

新增界面文案包含新字时，下载上游两个 TTF，分别保存为 `regular.ttf` 和 `medium.ttf`，用 fonttools 4.61.1 运行 `python scripts/pack-ui-fonts.py <源字体目录>`。脚本检查上游文件 SHA256，并收录当前脚本字符和可打印 ASCII。

## 武器规则

| 武器 | 已接入行为 |
| --- | --- |
| 草鞋 | 红 IV 实际完成第三次回弹后，该次命中额外击退 25% |
| 手戟 | 白蓝回原出手点，蓝以上回程提速 20%，紫红回玩家当前位置。每装备槽至多一轮主戟。红品回程切到三名不同敌人并接住时，补掷一次 0.55D 去程 |
| 贯石弩 | 约 180ms 起手。红 IV 在第三次贯穿时追加半径 52 的碎石，至多两目标、各 0.30D，触发正矢和碎石同轮去重 |
| 火油壶 | 蓝 II 油洼 1.7 秒，紫红 2.65 秒。同槽保留两个油洼，紫红在距离 180 内生成宽 28 的火线。红品首次有效踩线追加 0.30D，油洼、连线和短焰使用同一持续命中上限 |

使用正式关卡、无尽与演武共用的攻击路径。实装按现有规则在对应槽卖出或替换时清理它的持续油洼和火线。基础伤害、价格、解锁记录和本命以现有规则为入口。贯石弩穿过前三敌的反馈使用局部共用亮点。

## 验收与后续范围

- Cocos WebGL 用触摸事件从首页进选关、技能、设置、演武和黄巾第一波。战斗样板、张角起手、补给、结算用隔离浏览器和受控夹具调用真实运行方法。实渲染截帧核对字体、字号、演武选中项文字、开始触控及首领动作。
- Cocos Creator 3.8.8 本地微信产物在 `build/wechatgame`，主包 2.38 MiB，全包 12.05 MiB，复用现有已校验的远程资源版本 `v95-5eb9f0730a24a17b`。
- [微信桌面模拟器](../../art/reviews/handcrafted/wechat-validation.json)在独立构建副本验证新字体名、两种字重与系统字不同的实测字宽、加粗的开始按钮，以及进入第一波和老版农兵起手帧。验收前后存档相同。二维码用于手机复验。
- `test-armory-redesign.cjs` 调用实际攻击、碰撞和清理方法，核对第三跳击退、走位回戟、三敌且接住才补掷、贯石弩碎石去重、火线灼烧和升阶文案。
- 对照稿里环绕战地的桃枝、矮栅和岩石属于外围陈设。地表使用旧版拼接画面。战斗页的弹体与通用命中使用现有表现，补给保留足够空间显示真实的升阶、价格和范围。
- 武器四档机制的运行范围以本页四件样板为准。完整逐件设计见[武器设计稿](../weapon-system-redesign.md)。
