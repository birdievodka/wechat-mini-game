# 桃园乱斗 v2.2 调整

2026-11-12，版本 `orchard-v2.2-compact`。

- 地图宽高按当前屏幕设计视野各1.5倍配置，所有角色、敌人、镜头和中立目标使用同一边界。
- 清除固定的大桃树、推车、石头、栅栏和道路。地面保留草地贴图，稀疏小花；不再生成64个大型装饰。
- 小桃树随机刷新，首次约8—12秒，之后40—60秒检查；最多两棵，约82×86单位，小于角色高度。不会移动、不造成伤害，正常武器可命中，受击轻晃，击倒一次掉一个桃子，不给敌兵击杀奖励。桃子拾取回复一颗心，五心上限；满心时保留，不随补给自动回收。
- 20秒热身后原地进入无限模式，显示2.6秒“难度升级”。不弹出出征购买页，不清除场上敌人/弹丸，不重置角色、镜头和移动输入，音乐不中断。保留原30金币热身奖励和回满五心，并直接发放第二把初始武器，代替原先弹窗里选择第二件装备的步骤。
- 武器栏在装备同步时立即创建，缓存校验包含武器实例与槽位节点数量；首件武器不再依赖后续帧更新。增大图标、加武器名称。

新增回归：不同屏宽的1.5倍世界边界、热身衔接保持位置/镜头/输入/敌人/音乐、首帧初始武器图标与名称、小桃树静止/攻击/单次掉桃子/回血结算。原音乐、碰撞、技能、六武器、三选一交易回归同时保留。
