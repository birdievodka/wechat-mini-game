# 三英雄灵宠与多英雄首通奖励：实现说明

2026-11-18，用户已批准三宠设计并要求一起实现武器调整。本功能已接入，与并行无尽/设置改动共存；当前运行版本读取survival.SURVIVAL_VERSION（合并后stage-v9.18-endless-settings）。原v9.16“仅提案”已由本实现替代。

## 宠物取得与战斗

每英雄有效连续首通第5关后永久取得自己的宠物；现有有效S05通关记录直接生效。下一次挑战/重试自动参战，不占六武器槽、不占技能按钮，无敌方目标身份、血量、碰撞或挡弹能力。

| 主人 | 宠物 | 实际自动攻击 |
| --- | --- | --- |
| 小刘 | 桃桃兔 | 每1.2秒一发桃核，射程400/速度640；主伤42，向140范围内另一敌人再弹一次25，同敌一次。优先瞄准远程兵，沿路敌人仍可截到实体弹体 |
| 小关 | 小青蛟 | 每1.5秒朝锁定方向甩尾，.18秒后165半径140°青刃；每敌54，最近6目标上限、一次一击 |
| 小张 | 橘虎崽 | 每1.8秒短扑，.16秒起跳/.42秒落地、最远220；主目标60/落点R70附伤24、主目标不重复，合计5目标上限；主普通兵晕.25秒、同敌3秒限一次 |

宠物不继承力量、武器品质、攻速、暴击、分裂、弹射、武器/技能伤害或本命三连。正式S01–S06伤害倍率.4/.5/.65/.8/.9/1，v10.13.6 起演武跟随备战所选关卡，无尽保持满强度。敌人的盾防向/藤甲等防御保留；兽群冲锋无敌也阻止宠物。宠物击杀真实普通兵正常掉币与15击杀充能，Boss/小Boss/召唤/中立不计。

PetRuntime只模拟、10Hz索敌、不用战斗随机数、最多2颗宠物弹，与普通弹共享160活跃额度。普通跟随在英雄侧后90，追赶速度有上限，只有已屏外且落后320才回位；攻击与扑击落点锁定，不能绕全图无穷追踪。暂停、购物、后台、准备与演武配置冻结；清场/重试/死亡/离开清理状态。

## 已采用素材

采用[宠物设计稿](../art/concepts/hero-pets/design.png)。15动作源图位于art/runtime-pets/source.png，完整内置image_gen提示在prompt.txt，裁格与SHA256见manifest.json；scripts/pack-pet-art.cjs只做确定性裁格/注册/打包。

运行图assets/remote-content/pets/pets.png：512×512/1MiB解码/292298字节PNG，每种5帧（常态、眨眼、小跑A/B、攻击）。每物种独立统一比例和基线，真实透明边缘。PetView每处只1个Sprite，跟随/呼吸/扑跳是纯表现；地面影、桃核、青刃/爪印复用原共享Graphics，不新增宠物Graphics、刚体、粒子系统或引擎模块。

pets远程Bundle仅取得宠物的菜单/战斗准备和首次获得结算加载，未成长首屏不请求；菜单切无宠英雄先清引用再释放，退出/析构沿AssetScope租约。初得宠物时结算显示实际宠物和名称，备战/胜利左侧展示以免被右侧纸卡/地图遮挡，失败为闭眼陪伴姿态。资源失败使用现有准备/重试流程，不用隐形宠物攻击代替。
