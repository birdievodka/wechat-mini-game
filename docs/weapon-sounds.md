# 当前武器音效与源片段

当前音效路由以`assets/scripts/weapon-sound.ts`为准；36武器按类别复用已有片段。下表是现存音频文件的合成来源名，其中绿豆/擀面杖已从武器目录移除，文件名为兼容别名，不代表游戏仍有这些武器。草鞋继续使用用户提供的原始打击声；其余五种武器各生成出手和命中两段短音效，共10个原创合成音频，无外部采样。未增加草鞋风声。

| 武器 | 出手 | 命中 | 播放时机 |
|---|---|---|---|
| 草鞋 | 无 | 原有“啪”声 | 飞鞋实际命中时 |
| 绿豆袋 | 豆粒轻碰，100ms | 清脆豆粒击打，85ms | 豆粒发射与实际碰撞；同帧穿透限频 |
| 桃枝 | 木质弹拨与短法术音，180ms | 轻法术爆开，260ms | 发射与范围爆开；每次范围攻击只响一次 |
| 杀猪刀 | 极短金属擦动，70ms | 厚实切击与短金属余音，150ms | 出刀帧；命中一人或多人均只响一次 |
| 擀面杖 | 轻木质短拍，80ms | 较低、空心的木头重击，200ms | 出手帧；命中一人或多人均只响一次 |
| 爆竹 | 短引信噼啪，140ms | 脆裂爆炸与低频冲击，330ms | 投出与爆炸；到射程终点空爆也有声音 |

空挥不会触发命中声。弹丸保存发射武器身份，不根据当前英雄或第一格武器猜音色。玩家受伤保留既有声音。音乐开关与音效开关互相独立；暂停、后台、换关和退出清理全部音效。

最多6个音效声道，音乐使用独立声道。按具体音效限频，避免一种武器压掉另一种；出手音优先级低于命中，玩家受伤优先级最高。范围攻击在爆开/挥击事件级触发音效，不为每个受伤目标叠播。出手音量0.16–0.20，命中0.35–0.48，配置集中在 `assets/scripts/weapon-sound.ts`。

## 文件

- 游戏音效：`assets/sfx/*.wav`，PCM16、24 kHz、单声道，总计77,000 bytes，独立 `sfx` 本地分包。
- 草鞋原声：`assets/battle/audio/sandal-hit-pcm.wav`，保持原文件不变。
- 18秒对比试听：`art/audio/weapon-sfx-preview.wav`。每3秒一种武器，依次草鞋、绿豆袋、桃枝、杀猪刀、擀面杖、爆竹；每种各演示两次出手与命中。
- 渲染脚本：`scripts/compose-weapon-sfx.py`；检测数据：`art/audio/weapon-sfx-manifest.json`。

```sh
/tmp/taoyuan-audio-env/bin/python scripts/compose-weapon-sfx.py
```

渲染环境与配乐脚本相同，需要Python、NumPy和SciPy；游戏运行时不需要这些依赖。

## 验证

`npm test` 验证10段文件的时长/格式/无静音/无削波/端点衰减、六武器实际攻击路由、空挥、扇形与范围攻击只响一次、穿透限频、爆竹空爆、在途弹丸身份、混音优先级及静音；微信构建检查 `sfx` 分包入口和4 MiB预算。
