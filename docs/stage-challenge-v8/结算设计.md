# 分关挑战通关结算：解锁展示稿

状态：初步设计，不是实机，不改运行代码。例为黄巾起义，名将张角被击败后结算，不能写成六关全部通关。

## 账号首次解锁内容

左侧选中少年英雄开心亮相和“胜”章，右侧暖纸卡把实际解锁内容直接列出来，顶部玉绿小签“全英雄可用”。不能只显示“武器+6/道具+6/技能+2”让玩家猜是什么，也不新增逐个领取按钮。

黄巾关展示完整14项：

- 武器6：太平要术、五雷符、吞天葫芦、七星宝刀、桃花枝、爆竹。
- 道具6：趁热打铁、风骚小碎步、脚底抹油、穿云签、一鞋两响、老刘的鞋油。
- 技能2：八门金锁、火烧连营；技能行可统一附小字“击杀15重置”。

每项有一致画风图标、名字、小“新”签；点图标可看说明/升阶，不在结算主屏堆属性表。新武器/被动取得的是共享商店资格，须当局刷到并付钱购买，不可设为初始；新技能取得的是共享备战装配资格。主按钮“挑战下一关”回备战并预选下一关，保留换用新技能机会，初始武器仍限3把基础款；次按钮“返回备战”保留当前关，没有“领取后才保存”的步骤。

## 本英雄首次过关，但账号已领过内容

例：小刘已解锁黄巾奖励，小关第一次打过黄巾。小关依然开心庆祝，独立进度变为1/6，并解锁小关的虎牢关。共享内容区显示“本关内容已解锁”“全英雄可用”，用紧凑的武器6/道具6/技能2摘要与查看入口，不再出现“新”、领取或重复发奖动画。

同一英雄重复过关时显示“再次告捷”与成绩，可标刷新纪录；已解锁的下一关只显示可挑战，不再冒充新关卡首次开启。末关主按钮改“返回备战”，不得显示不存在的第7关。

## 信息与动态

- 层级：胜利/关卡 → 新解锁内容 → 本英雄新关卡 → 导航；统计只保留用时、击败、按角色上限显示的剩余心数（小刘/小关5、张6），不展示永久金币余额、经验等级或购买价格。
- “全英雄可用”只放在内容卡；“小刘/小关新关卡：虎牢讨董”独立放在下方，不能让共享标记看起来连关卡也共享。
- 成绩为工程示例，不是测得通关记录。英雄沿现有头/袍/手/脚分层轻跳、眨眼，武器/被动小卡顺次淡入，技能卡短金边扫光；约0.8–1.2秒内完成，点屏可跳过，导航不强制等待。
- 标准横屏首关14项一次展示完，六武器一行、六小道具一行、两宽技能卡一行。第2/3关现各有15项（7/6/2），武器行支持七格、窄屏可4+3换行；其余奖励数由数据驱动，不写死任何一关的数量。窄屏优先压缩留白、保留可读字号；确实不足才让内容区纵向滚动，标题/共享标签/导航固定。
- 胜利回调先保存英雄通关与账号解锁收据，再展示实际新增集合；图标/标签由本次发奖差集生成，不能仅按通关关卡号把已经领取的内容再次标新。
- 图稿引用现有少年肖像、武器/技能图标画风；示意道具图标仍需投产时映射真实ID。主稿与已解锁状态都只是概念，未替换当前ResultView。
