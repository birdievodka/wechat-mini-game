# 桃园乱斗 v2.3：连续采购与远程构筑

版本：`orchard-v2.3-ranged-supply`，2026-11-12。

## 拾取

生命心和桃子无论是否满血都可以吸附拾取。未满血恢复一心，满血消耗掉落物但不增加生命，普通模式始终不超过五心。保留落地延迟、吸附距离、掉落物寿命和单次结算保护。

## 补给

- 每屏三张商品均可购买，每张本屏只买一次。已购商品原位置显示“已购入”，避免重排误触。
- 买完仍停留补给页，战斗、技能冷却、敌人和计时全部冻结，属性和六武器装备立即更新。点击“继续战斗”才进入准备倒数。
- 可以连续刷新，刷新后补充三张新卡并允许再次购买，包括再次出现的普通被动道具。天命强化依旧本局唯一，恢复商品依旧每60秒限购一次。
- 每次补给基础刷新费为 `5 + 3 × 已刷新次数`，即5、8、11、14……。下次补给重置次数；“货比三家”仅优惠本次补给第一次刷新，最低1金币。金币不足不扣费、不增加次数。
- 六武器上限、满槽指定出售替换、升阶、合成及至少保留一件武器等规则延续。买过的卡不能重复扣款，升级商品按报价等级展示。
