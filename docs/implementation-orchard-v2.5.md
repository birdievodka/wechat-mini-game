# v2.5 英雄选择页

版本：`orchard-v2.5-hero-menu`。

按照 `art/concepts/hero-select-v2.5/03-select-hero-simple.png` 实装横屏英雄选择页：

- 标题“选择英雄”，桃园背景降低对比度，左上保留游戏书法标识。
- 刘备、关羽、张飞并排三张大卡，人物各出现一次；当前角色卡片金色描边、勾选与轻微抬起，点击可切换。
- 仅保留卡片姓名和简短定位，移除底部属性条、爱心、数值、等级、重复大头像与说明文字。
- “开始”为唯一主按钮；删除首页测试入口和初始武器选择页面。
- 默认初始武器：刘备草鞋、关羽绿豆袋、张飞桃枝，点击开始直接进入20秒热身。局内六武器、商店购买与替换规则延续。
- 返回选人后保留上次选择，重新开始重置金币、生命与本局成长；启动和返回菜单不自动开始战斗。

## 素材与适配

通过内置 imagegen，参考已确认设计稿生成独立背景及带透明通道的3×2图集（3位角色、标识、标题、空白按钮底板）。原始素材分别位于 `assets/hero-menu/background.png`、`assets/hero-menu/atlas.png`；提示词位于 `art/concepts/hero-select-v2.5/runtime-prompts.json`。

人物、背景、文字与按钮分离，英雄卡及命中区域为实际节点绘制，不把整张设计稿用作可点击背景。按钮文本、姓名与定位采用实时文字。独立 `hero-menu` 分包，避免增加主包或把旧角色资源包挤过4MB。素材加载失败时保留可交互的基础菜单。

横屏按当前宽高缩放，左右预留安全区，右上避开微信原生胶囊，开始按钮保留底部安全边距。

## 检查

组件回归验证三位英雄单选、唯一选中态、无属性/测试/选武器入口、一键默认武器开局、20秒热身、五颗心、返回保留英雄；验证1334×750、1622×750、1875×750的卡片与开始按钮安全区。原战斗、剑阵、连续采购、音效与敌人技能回归继续通过。

## v2.5.1：取消热身赠送武器

按用户要求，20秒热身结束不再自动复制初始武器。保留原地进入无尽模式、金币回收、30金币及回满生命，已有武器与实例编号保持不变；后续武器通过补给购买。回归检查验证过关与重复调用均不增加武器或消耗新实例编号。

## v2.5.2：保护期与受击反馈分离

切入无尽及补给后免伤保护不再占用真实受击计时器。保护期间仍阻挡伤害，但不会凭空闪红、显示旧扣血数字或触发受击加速；真正受伤仍扣一心、闪红、击退，并拥有独立受击无敌期。退出战斗与重开清理两类计时和反馈。暂停及补给准备倒数保持原冻结规则。
