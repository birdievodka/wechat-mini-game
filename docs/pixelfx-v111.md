# v11.1 战斗特效与威力更新

本轮起始运行版本为 `stage-v11.1-pixelfx`。正式关卡、无尽和演武共用战斗实现。更新覆盖 3 把本命武器、30 把普通兵器、40 种普通兵、七位首领 21 招、六关精英与 12 招主动技。既有角色和场地保留。新版特效从实际出手、命中、危险区和场上弹道取数据。命中闪红继续使用真实扣血后的 0.10 秒时钟。

`stage-v11.1.1-arrow-rain` 修订 G22 万箭齐发。施法点短暂显弓，前三轮各 18 支白羽交替斜落，末轮 28 支金羽重矢。按 0.22、0.47、0.72、0.97 秒依次落地，地面留短钉痕和碎光，末轮金星与分段余波更明显。半径 400、范围判定、前三轮 0.22S 和末轮 0.42S 延续 v11.1。箭矢图和落地亮点使用既有图集与共享绘制，固定散布点仅用于画面。

新版逐轮回归覆盖施法前期无伤、四次结算、施法后移动与半径边界。Cocos 桌面 WebGL 帧确认 18/18/18/28 支箭矢进入共享层。六武器、78 普通兵与双首领的 60 秒加速压力中，采样峰值为 56 个材质四边形和 276 个粒子，沿用 96/280 上限。微信本地包构建通过。

## 七位首领、普通兵器与小兵

张角三符雷锁按施法时的距离决定通电顺序。吕布三冲的第二冲侧切并独立锁向。董卓的三坛酒使用间距校验，边缘处仍保留可走一侧。袁绍箭墙使用旗位和弹体方向，雨点与当前在场弹体、危险区的候选落脚位冲突时顺延。曹操两枚纸影分别关联一个半域，死亡即取消对应一半。孟获的两头战象间隔 1.75 秒进入危险段，前象完整冲锋后至少留出 0.30 秒。司马懿的三招为玄门落子、太极化龙、北斗坠星，四棋逐次锁定，双龙从两侧对穿，三颗星石以 0.40 秒间隔落下，各留 0.43 秒持续危险。

普通弓弩的白翎、蓝钢、紫漆、金棱、青翎、赤翎分别引用 PixelFX 箭矢，复用原弹体 Sprite。伤害和落点仍以原真实弹体为准。E40 黑白两棋使用同一波的各自落点，E10 实际治疗成功才在受疗单位位置出治疗花。普通兵器按既有武器路线使用木屑、金属碎锋、尾迹、符纹及火花。品质的追加效果继承游戏内现有触发条件。

## 资源与预算

`art/runtime-pixelfx/manifest.json` 记录固定的 PixelFX 源码提交、取帧时刻、发射种子与色板。构建使用预烘焙帧，保留 MIT 许可。呈现分包新增一张 512² 最近邻图集，64 帧，解码增量 1 MiB。二次动画借现有四共享层和素材池，预算仍为普通 64 个材质 Sprite、共 96 个，280 粒子、160 友弹、80 敌弹、6 危险区、4 主招。基础轨迹和危险边使用共用几何，装饰分配失败时仍按正确的路径和范围绘制。

244 项原库用途台账是全量选材规划。v11.1 的共享图集包含 27 个不同上游模块、36 组配色或形态。未落到真实调用链的图鉴、营地、天气和其他条目仍按提案管理。

## 验收入口

- `npm test`、`npm run typecheck` 和 `npm run check`。专项覆盖实际施法、每敌及整招上限、弹道扫掠、纸影半域、落点锁定、真实格挡及回收。
- `node scripts/report-pixelfx-balance.cjs <输出路径>`。单目标、八人纵列、十二人围攻、Boss 混合四种布景，共 48 次实际技能结算。
- `node scripts/capture-pixelfx-review.mjs <输出目录>`。本机 8766 WebGL 与 9336 Chrome 调试端口，按真实战斗出手取工程帧。
- `node scripts/profile-pixelfx-review.mjs <输出目录>`。两组六武器、78 普通兵与双首领，在桌面 Cocos WebGL 加速模拟。工程计时、手机帧率、正常游玩分开评价。

## 验收记录

WebGL 工程帧覆盖 106 项主要战斗内容及 20 项精英、骑宠或辅助反馈，共 126 张。用设计稿对照三个本命、护体剑阵、火线、雷柱及司马懿的招式。核对了关羽半圆边界、张飞刺光与枪轴衔接、实体飞剑数量和玉符余量、施法朝向及两龙对穿。预告和命中按运行时间取帧，工程场景恢复到营地并校验进度。

平衡脚本执行 48 次主动技结算及司马懿三招的直行采样。三个起点覆盖中心和两处场边。270 世界单位/秒下九组各有无伤路线，站立在玄门落子的锁定点会接触四枚棋子，1.2 秒受击保护按正式规则限制扣心。战场构型是可复现的工程布景。

性能测试复用两个实际战斗布景，各推进 600 秒。固定六武器、78 普通兵及双首领，覆盖 G22 多批箭雨及 G25 长时间多剑。在桌面 WebGL 核对材质、飞弹、危险区、粒子上限和后段内存。Node 套件另覆盖 160 友弹饱和与源死亡清理。压力记录的桌面引擎计数与真机表现分开。
