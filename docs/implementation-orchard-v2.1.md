# 桃园乱斗 v2.1 实装记录

2026-11-12。运行版本标识 `orchard-v2.1-orbit`。

## 本轮实现

- 4000×2250世界坐标，镜头跟随，屏幕HUD固定；桃园草地、道路、树木/推车/石头装饰，按视野显示装饰。
- 敌人随机出生于周边、前方、全地图，含安全距离和显形预告。预告阶段不攻击、不受伤、不阻挡，显形后缓冲；远处普通兵可重新预告入场，保留生命。
- 鸡、兔、猪随机出现，可自动攻击；击败掉落一颗生命心，不计敌兵经验/金币。心可恢复一心，满心不浪费，暂停冻结寿命。
- 半透明三选一：战场保留、冻结；武器最多六格，支持出售/合成及满格净额替换，实例累计投入决定回收价。
- 十二把武器，包含突突枪、霰弹枪、火箭筒、飞剑、五雷符、葫芦；接入散弹、追踪、分裂、跳跃落雷、范围爆炸与六段轻聚怪。
- 48种自动被动道具，六类；无限购买叠加、收益递减、上限后转为伤害等溢出收益。行囊分类分页显示。
- 刘备以德服人30秒、关羽豆破千军26秒、张飞桃园狮吼32秒。技能伤害随装备成长，暂停/补给/倒数不推进冷却。电脑空格/E也可释放技能。
- 移除经验条，保留姓名Lv.和自动升级。固定五心，不增加生命上限。

## 多武器表现（本轮追加要求）

一把武器仍为握持/投掷动作。两把及以上采用周身椭圆分布，半径约94×76；六武器覆盖上方、两侧、下方，不新增角色手臂。武器本体独立挂在角色节点下，前后层级按环绕位置排序；攻击从各自环绕点释放，互相独立计时。仅有两只解剖手臂，环绕状态不显示握拳副本。

## 素材

使用内置image_gen生成运行素材：`assets/meadow/ground.png`、`assets/orchard/decor.png`、`assets/arsenal/weapons.png`、`assets/talismans/items.png`。分别独立分包，避免挤占原有接近上限的资源包。生成提示词保存在 `art/concepts/survival-v2-1/runtime-prompts.json`。

现有六武器音色继续使用；新武器复用最接近的现有音色，尚未逐把制作新录音。

## 验证与限制

类型检查、场景/构建配置检查、音乐/音效/碰撞回归，以及真实组件场景测试。新增测试覆盖：跨屏与固定HUD、240次出生采样、六武器父节点/环绕点/无多余手臂、动物掉心/满心/暂停、三人物技能冷却/防连点、48道具首购与100→101件仍有效、满槽替换/重复交易、六种新武器伤害与非递归分裂。

地图首版装饰主要不阻挡，尚未引入复杂地形寻路。动物暂用程序绘制的卡通动作。数值是可玩的首版基准，真实手机帧率和人类生存时间分布仍需用户体验继续校准。

## 发布验证

已完成微信构建，并使用微信开发者工具CLI重新编译。运行时确认版本 `orchard-v2.1-orbit`，ready=true、正式选人页、五心、经验条不可见，87项帧资源与64处地图装饰就绪。测试会话中实际确认六件浮空武器的坐标、独立父节点和攻击，以及技能按钮触发30秒冷却、半透明补给展示；最后刷新回正式入口，不保留测试注入的装备/金币。过滤控制台未见错误。
