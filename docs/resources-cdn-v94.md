## 构建与上线边界

`build:wechat` → `stage-cdn-assets` 将 Creator 的 remote 数据移到 ignored `cdn-assets/releases/<version>`，将本次服务器地址固定进微信settings，然后移除包内remote重复副本。校验13个远程Bundle都有本地JS桩、有配置和native文件；8个本地必需分包保持。`cdn:publish` 只上传静态白名单，106文件逐个HTTP下载/长度/SHA256校验，成功后记录published；普通构建不隐式发布外部资源。

本次微信构建：原总包19.00MiB → 9.69MiB（约−49%）；主包2.20MiB，各分包最大1.54MiB；CDN7.89MiB。源码素材保留不等于重复进包。详细发布清单在 `cdn-assets/release.json`，校验凭证在 `published.json`。缓存、联网首取耗时、微信打包报告可能有少量平台开销，不能把构建大小当作手机实际流量。

用户确认后台未添加域名：需要微信公众平台“开发管理 → 开发设置 → 服务器域名 → downloadFile合法域名”添加上述HTTPS主机。该账户设置不在仓库里；在完成前，CDN公开可访问和IDE通过均不能证明手机高级关卡/音乐可下载，不关闭域名校验来掩盖此条件。
