# v4.2 选人页：桃园演武场

选中英雄直接站在无人物的桃园演武场夯土地面上；移除原合影海报和奶黄色圆盘。中央留白，两侧小营旗、木桩、桃枝和远山提供环境感。背景按实际宽高比等比铺满，保留背景自然明暗，不叠加条带式渐变。

上方分层英雄缩放2.2，原点0/15；下方五个100×100纯头像，姓名只显示在英雄脚下的玉绿名签；开始仍水平居中，图鉴保留。刘备双手握鞋、关羽双手抬担、张飞挥尖刀、赵云转枪、孔明摇扇；真实闭眼帧、头动、呼吸继续播放。菜单独立时钟不推进战斗，不改存档或消耗战斗随机数。

新背景由内置image_gen生成，完整提示词和来源见[素材清单](../art/concepts/hero-select-v4.2/manifest.json)。运行贴图为1536×864 JPEG约166KiB，旧背景移至art归档，不进入发布包；Loading海报保持独立。

类型检查和现有组件回归通过，覆盖五英雄眨眼与武器动作、选择复用、菜单不推进Run、直接携默认武器开局和三种横屏安全区。微信构建与实际画面核对另记录在本目录validation文件。

加载页状态文案统一为“英雄集结中… n%”，不限制英雄人数。
