# 横扫六合 A金锋回旋实装

版本 `chronicles-v5.1-golden-sweep`。用户确认A版，现已实现并构建加载到微信开发者工具；B/C不采用。

## 本次变化

- 旧细圆环和六个箭头替换为首尾收尖的金白厚刃月牙，金色刃身、暖白刃面、细锋边和两层低透明拖尾共同顺时针扫过。
- 前后两层绕过人物，短笔触和少量切向细屑增强动势，中心保留角色和战场可读性。世界顶视圆形半径与真实判定一致。
- 只有真实命中的敌人生成小型金白楔形闪、定向碎屑；借用原受击闪白/形变/击退，避免旧的青色金属火花混色。空放没有伪造命中点。
- 五英雄均可使用同一短暂拧身、压身、头部反向小摆与回正；动作不移动位置、不改变朝向、武器和手臂数量。首次命中借用既有微小战场震动，HUD不震。

保留0.80S、半径250、最多10敌各一次、击退300、基础22击杀。主体0.4秒收回，接触闪0.19秒；没有新增伤害次数或持续判定，没有加入新免伤、硬直或实际停帧。

## 性能和包体

`sweep-effects.ts`使用48段预计算单位轮廓及共享坐标缓冲，复用原前后Graphics层、32技能视觉槽和280粒子池，未新增位图素材或独立发射器。10敌命中时主体加接触为11个视觉，取帧中粒子峰值114，非全战斗峰值。最终构建18.51MiB、各分包低于4MiB。未宣称手机60帧或iOS闪退已解决。
