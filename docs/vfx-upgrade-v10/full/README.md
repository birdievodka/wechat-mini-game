## 风格与机制关系

华丽感来自主体材质与连续运动：金白锐锋、青玉刃面、橙金翻焰、蓝青厚水体、粗细雷芯、黑白玉石实体；不把所有攻击都放大成同一光圈。普通兵效果紧凑，玩家普通武器持续可读，主动/Boss负责高潮。高亮集中、尾迹收尖、余波迅速回收。

设计板提供美术峰值和阶段示意，飞行/接触细节可同版展示；实际接触必须按弹体抵达、扫角、范围、tick与真实事件生成。图片的透视、夸张受力姿态、临时施法光弓/光刃不授权新增击飞、伤害、武器槽或扩大攻击距离。完整连招底部三格对应三次真实出手，不是一次结算三次。

首轮核对重点返修：孟获保持地面指挥、动物独立；阴阳双龙留贯通草地通道；火线/箭雨/八门按实际施法点居中；敌方单兵攻击只对主角表现受击，旗手/军医只作用普通友兵。普通E40两雷区与精英军师两棋阵分别设计，不混用历史描述。

逐项复核还区分：普通飞剑常驻环绕、普通双股剑交替与成长X剑气；三雷符三角、四铜钱双侧通道、三独立酒火池、四弓手与两台三连弩车、三枚棋子；小关赤兔/青龙刀、小张黑猪/蛇矛，以及绿金E25象兵统领。源图中的运动或受力夸张不能替代这些身份与战场结构约束。

## 重建文档

`python3 build-book.py`重建文字方案与内嵌数据HTML。使用配置了reportlab/Pillow/pypdf的Python运行`build-pdf.py`导出PDF与缩略核对文档；当前作者环境使用Codex工作区依赖Python和Mac Arial Unicode字体。生成器只读取manifest/现有PNG，不调用生成API、不更改游戏代码。

项目skill与特效skill同步记录的是本轮设计交接及待审边界，当前运行基线仍为stage-v9.22-battle-text。
