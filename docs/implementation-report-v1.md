## 12. 首版实现与验证记录（2026-11-11）

设计先于代码完成；正文和8张设计图已上传并回读核对。现在首版代码已实现：三英雄选人菜单、三种自动武器、12件可叠加道具及角色挂件、击杀经验与回营三选一、商店购买/刷新、八个60秒关卡、投矛手/骑兵/首领、胜负结算、暂停/后台暂停、重开、音效偏好和本地最佳关卡。

### 自动验证

- 类型检查、场景/AppID检查、移动/连续碰撞/旧功能回归通过。
- 经验小数与溢出、多次升级、商品重复购买保护、金币不足保护、同款最多3件、刷新费递增、属性上限通过。
- 真实组件启动、选人、回合结算只发生一次、升级后购物再入下一关、死亡与重开清理通过。
- 关羽按路径穿透两个不同目标且第二击70%；张飞爆炸只结算一次；投矛预警后出手、骑兵锁定冲刺方向、首领单次生成及限时胜负通过。
- 三角色八关状态循环通过。此项使用无敌和末关强制击杀，只检查流程，不用于声称平衡。

### 正常生命规则的机器人试打

另跑一组固定随机种子20261111、30fps的简单机器人。保持正常受伤、敌人、商店、经验和首领血量；它绕圈移动、对近敌做排斥避让，首领阶段尝试在首领周围走位；升级优先伤害/攻速，再取防御；仅用赚到的铜钱购买当次商品。此组没有开启无敌或强制击杀。
