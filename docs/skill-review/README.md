### 百步穿杨

现有效果：金色战弓与八支实体红羽箭。

### 冲锋破阵

现有效果：厚实体青白枪锋与双侧断笔尾迹。

### 横扫六合

现有效果：A金锋回旋实体厚刃与双拖尾。

### 八门金锁

现有效果：八方实体门印与接触锁链。

### 火烧连营

现有效果：水平连续火线、四层卷焰与焦痕。

### 水淹七军

现有效果：深浅厚浪墙与断续白沫。

### 星落五丈原

现有效果：实体岩核流星、金紫焰尾与碎石冲击。

### 背水一战

现有效果：赤色战旗、红金战气与出手拖尾。

### 护体剑阵

现有效果：四柄实体青剑与三枚格挡星印。

### 震军号令

### 雷霆万钧

现有效果：雷印预表现、粗雷柱与分叉冲击。

### 万箭齐发

现有效果：覆盖圆形区域的四批实体箭雨。
