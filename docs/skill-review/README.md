## 当前表现评审

### 神行百变

现有效果：绿色加速箭头与脚下细环。

重做重点：与伤害和攻速增益共用上箭头造型，缺少疾跑轨迹。

### 回马一枪

现有效果：后方金白细枪线与箭头。

重做重点：直刺主要是线条，缺少长枪实体和收招。

### 冲锋破阵

现有效果：青白双轨与突进箭头。

重做重点：更像指向线，角色起步和终点冲击缺少层次。

### 净心诀

现有效果：绿白六边形与金色刻线。

重做重点：与其他防护技能轮廓相似，净化瞬间不突出。

### 百步穿杨

现有效果：三段金白箭线。

重做重点：当前为窄线命中与短箭迹，缺少明确的飞行过程。

### 横扫六合

现有效果：金白厚刃月牙与双层错位拖尾。

重做重点：已实现A金锋回旋；手绘笔触的细腻度仍可继续打磨。

### 金蝉脱壳

现有效果：紫色纸替身与闪避残迹。

重做重点：替身外形过于几何化，闪避与诱敌关联不强。

### 声东击西

现有效果：橙色纸替身与延时火焰爆点。

重做重点：替身与金蝉相似，等待爆炸的节奏提示较弱。

### 铁壁架势

现有效果：青色双盾板与六边护环。

重做重点：双盾具备剪影，但抵挡剩余次数缺少明确反馈。

### 背水一战

现有效果：橙色战旗与三个上箭头。

重做重点：与加速增益相似，伤害增强没有持续冲击反馈。

### 破釜沉舟

现有效果：金旗箭头与额外双盾外观。

重做重点：与背水一战容易混淆，攻速提升难以直接辨认。

### 纸甲成兵

现有效果：三名绕身纸兵与小箭。

重做重点：三角纸兵偏简化，攻击姿态和命中反馈不足。

### 草船借箭

现有效果：木船白帆与四支装饰箭。

重做重点：船体有辨识度，但箭数不反映实际吸收数量。

### 火烧连营

现有效果：三处橙黄火焰依次展开。

重做重点：火苗较细碎，主爆点与燃烧层次不清晰。

### 水淹七军

现有效果：青色扩散水环与白色浪沫。

重做重点：范围清楚，但水浪体积和推进力度较弱。

### 奇门遁甲

现有效果：绿金八边结界与白色内环。

重做重点：与净心诀和护盾区分不足，结界缺少独特符纹。

### 妙手回春

现有效果：粉绿花瓣与白色回复十字。

重做重点：回复语义清楚，但缺少桃园主题的记忆点。

### 八门金锁

现有效果：固定双八角阵与八座小门。

重做重点：阵型清楚但线条薄，门与锁阵缺少开合过程。

### 虎啸山林

现有效果：金白扇形声浪与虎面。

重做重点：虎面已有特色，但轮廓与声浪的衔接较平。

### 暗度陈仓

现有效果：后撤双轨与紫白前向刃波。

重做重点：后退与刃波是两段简单线条，缺少鲜明终结动作。

### 雷霆万钧

现有效果：紫白多层雷柱与分叉电弧。

重做重点：单点雷柱较醒目，四次落雷的层次与余波不足。

### 四面楚歌

现有效果：四面紫旗与向内移动的圆形音符。

重做重点：军旗与其他增益旗帜相似，压制含义不直观。

### 万箭齐发

现有效果：十二道扇面穿透箭迹。

重做重点：覆盖面大，但箭体偏细，缺少齐射爆发感。

### 星落五丈原

现有效果：紫色坠星金焰与五角落地冲击。

重做重点：坠落有阶段，但落地冲击偏符号化，重量感不足。
