# v2.6：升级难度前先购物

版本 `orchard-v2.6-preparation-shop`。

流程改为：选英雄 → 20秒热身 → 热身补给 → 点击“进入无尽” → 原地提示“难度升级” → 无限生存。

- 热身结束先回收金币、发放原30金币奖励并恢复五心，打开半透明商店。此时仍处于第一关，难度和无限计时都没有开始。
- 初次货架为一把当前初始武器、两件适配被动道具；全部需要花金币购买，不赠送武器。
- 可购买三项，也可连续刷新后继续购买。初始刷新费用5金币，之后8、11……；首刷优惠道具按原规则生效。刷新后的武器从四种初始武器中随机出现。
- 商品购买后继续停留商店；允许合成与出售武器，也允许不买，点击“进入无尽”继续。
- 购物全程冻结敌人、弹丸、技能和战斗计时，暂停音乐，释放移动输入。保存角色位置、镜头和场上状态。
- 继续时原地进入第二关，显示“难度升级”，准备倒数与独立免伤保护沿用；不清场、不回出生点、不复制装备，保护期不触发受击闪红。
- 无尽计时从0开始，首次常规补给仍在30秒，首个精英事件仍在90秒；热身购物不增加常规补给序号，也不提前消耗事件。

回归覆盖：20秒准时打开商店、购物期不提升难度、三项付费购买/刷新再买、战场冻结与原位恢复、无额外装备、跳过购买、重复继续保护，以及后续30/90/180秒事件和音频/受击反馈生命周期。
