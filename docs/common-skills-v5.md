# v5 通用技能与击杀充能

五英雄自由携带一个技能；24技能本轮全部免费开放，预留unlocked/unlockHint接口，不实装付费或进度锁。威力为伤害、控制、生存价值的综合阶，不能解释为所有场景的严格DPS排行。

开局可释放一次；释放后充能清零。每击杀一个真实普通敌军（不含Boss、中立动物/桃树、召唤旗/眼/假身）+1，时间不回复。技能击杀也计数，但目标上限与充能门槛防止一次施法自充满；不储存第二发。补给/暂停/跨章保留充能；新局重置，存档存技能ID和击杀充能。F08改为充能效率，孔明固有10%效率仍适用于所选通用技能。

S为施法瞬间已装备武器的单目标理论DPS之和，再计入技能增伤；伤害、范围、每目标次数/总目标预算独立约束。防御技能按综合收益归阶。
