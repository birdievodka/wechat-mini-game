## A 首页与图鉴：入口轻、详情足

首页移除“选择英雄”标题，下方居中“开始”；左下“图鉴”、右下“演武场”均为次级入口，演武场允许无限生命与自由配置，不影响正式闯关。旧随机测试模式、角色属性面板和初始武器选择不恢复。v4.1改为上方单个分层动态英雄、下方五个纯头像选择位，姓名只在主展示区显示一次；默认武器参与各自亮相动作、眨眼和呼吸，居中“开始”与图鉴保留，不恢复属性面板。最新界面使用独立桃园演武场，英雄直接站地，不使用纸色圆盘或加载海报。

横屏图鉴顶部是返回＋“三国图鉴”＋敌兵／武器／技能。主体左侧约54%做4×3缩略卡网格，右侧约42%做详情，间隔与安全边各约2%（最终按刘海和微信胶囊裁避）；上下翻页或纵向滑动只动左列表，右详情保持稳定。逻辑设计高度750，字号正文24～28、标题34～40，点击区域至少64×64逻辑单位；支持小屏时将次要出处收进“更多”。这些是设计单位，不直接等同系统pt。

- **敌兵**：兵种／首领两个二级页。实装按全部／步兵／远程／骑兵／器械筛选；术士包含在远程，未提供阵营筛选。40类指机制身份，不把换皮算成新兵；首领页为7场战役／7位人物。
- **敌兵详情**：名称、角色剪影、题材标签、首登章；标准值／本章值开关；HP、速度、射程、总攻击周期、前摇、弹速、弹数、1心伤害、击退抗性、收益、弱点。标准值是C01比较基准，不是假称该兵C01就会出现。
- **章节值**：首页可切1～7章第1战段数值；没有战斗暂停图鉴入口。字段乘数清楚展开，移动基速、冲锋速度分开。Boss不乘普通兵倍率。
- **攻击示意**：本轮详情为静态立绘＋数值/文字，没有图鉴独立战斗沙盘；正式战斗已接入行走和攻击。通用技能没有试用。
- **武器详情**：近战／远程／法术筛选；四品质切换，实际单段伤害×允许段数、周期、射程、扫角、击退、暴击、弹速、范围、基准单体DPS、外圈系数、同敌命中上限、共享实例上限、价格和来源。点击品质后整张卡更新，不只变边框。
- **技能详情**：12通用技能按综合威力排序，展示基础击杀需求、伤害系数、范围、次数、保护和Boss减控；图鉴仅查看，选人页技能按钮负责装备一个。全部已开放，无专属技能分类。
- **收录与解锁**：全条目数值可查看；尚无遭遇/拥有收集计数。武器普通开池按击败章节解锁，新英雄默认武器不受此限制；图鉴没有永久属性奖励。
- 列表12项分页，切页签回到该类第一页，返回首页保留英雄；返回首页保留当前选中英雄。详情先展示攻击身份，再展开公式与出处，不把数据表一口气塞满移动端屏幕。

## C 长流程商店：能成型，也要继续取舍

继承六槽武器、卖出／合成和无槽位被动。三张卡可全买，刷新可继续买；每次进店刷新费5、8、11……，道具只优惠该店首次刷新。章间不重置装备、不赠武器、不反复补到28。购物战斗冻结、BGM继续。

第1章第0段商店继续采用现版特殊保底：至少一件非同款白I武器≤28金币，另一件同款白I按28；预算28通常只能买其中一件。第1章前30秒仍只投白I，之后该章蓝率25%再到50%；从C02起才使用卷表，避免扩展品质表悄悄改坏现版开局。

常规货架至少1武器；第1卷第二格80%为武器／升阶，以后50%；第三格优先被动或恢复。这里概率指卡位类型，下面40/35/20/5是**已经确定生成武器后的候选权重**，不能相乘混成总货架概率：

- 40%当前持有同款：利于合成；没有已持有且可升阶候选则把权重按比例分到其他组。
- 35%当前主要武器标签内其他武器：有构筑方向而非只出同款。
- 20%当前章间新开放的军械：章节新鲜感；开池后首次章间补给至少给其中一件可购买卡，不免费进背包。
- 5%已解锁全池探索：允许换路线；无有效目标时重分权重。

同一武器可能属于多个组，先抽组再在该组去重抽取，本屏原则上不重复同ID同品质；明确的“同款升阶报价”有独立标识。每卷实际候选以12～16家族为主：当前持有、其标签、本卷新武器优先；全池探索可跳出家族范围，已解锁不等于同时稀释到36等权。

品质合成仍两件同名同阶免费合一；红IV不再继续升阶。六槽已满时可指定替换和退款差价。保留最后一件武器保护，弹窗操作要能取消，不让小屏误触卖光。出售按累计投入40%，道具最高60%；买卖不得产出净金币。

### 长线价格与收入标尺

当前按补给次数不断涨价的曲线不直接外推到17章。现用固定章节指数：`I(c)=min(5,1.07^(c−1))`，同章刷新不再涨商品单价，只涨刷新成本。

- 武器价=`round(基础价×I(c)×品质系数×(1−折扣))`；品质系数1/1.6/2.5/4，折扣沿用最高20%。基础价见03，其中三初始武器为28。
- 普通被动价=`round(28×目录价格倍率×I(c))`。天命、回血沿既有独立倍率；不把新武器基础价套成全体被动价格。
- 普通兵金币按02基值，金币加成可增加金额但不得刷更多兵；章结算Boss基础奖励=`round(35×I(c))`，不是和遗留经验再发一遍。
- 每30秒战段结算给予整备金=`round(12×sqrt(I(c)))`，每章仅三次；第0段、Boss前后的购物不重复领取。C01每次12，C17约21；已在30秒边界发放并随交易保存，沿wavesCleared防重复，不复用旧stipend字段。
- 新征程第0段把累计总收入补到28而非额外送28；新英雄默认长枪或羽扇也不会重复赠一次。后续第0段只有实际击杀收入，章末金只发一次。
- 无足够金币时继续保留低价基础修炼卡，刷新不是强制扣费门槛；未花金币跨章保留，玩家可存钱买名器。

收入估算必须声明击杀率：以65%击杀率、前期平均威胁成本1.6／金币1.5，后期2.8／金币2.3估算，仅90秒三战段约收入130与290金币；另加第0段／Boss援兵实际收入、三份整备金、Boss奖励。暂设C01全章约230～320、C17约500～700金币作为采样目标。不是保证收入：跑图、清群与控制构筑的实际值要记录。

C17指数约2.95，白I基础价40约118、蓝约189、紫约295、红约472。单章预算用于一件红主力或若干蓝卡／被动，不要求每店全红。同款合成与旧核心仍有价值；若清兵率不足导致经济失速，先调整结算金或通胀，不按玩家装备动态削Boss血量。

### 被动无限购买的强度约束

保留现有60种被动及9种唯一强化，不新增大批未经验证的乘法机制。普通重复收益沿`unit×n/(1+k×(n−1))`递减，不把每件直接再乘1.1；攻速加法合并，暴击80%上限、普通攻击周期最低0.08秒／突突枪0.06秒沿现版。

长线评价同时记录输出、控场、射程与经济。本轮真实交易模型暴露初版后期HP过低，已将固定输出标尺调为152.05～4500；普通HP按标尺比值^.95，BossHP按标尺×40×个性系数。150条五英雄路径在65%清兵/65%命中假设下，Boss中位约33～53秒；强构筑可更快，弱构筑更久。完整分位表见../chronicle-balance.json。这不是战斗生存率，不证明低操作玩家一定能通卷。

远程追加弹数优先增加覆盖；同敌命中上限仍存在。全近战应靠完整扫角和高单体站桩补偿射程风险；不能让突突枪靠永久硬直封死所有兵。六把相同陷阱／火场／随从必须测试全局共享上限，图鉴的单把DPS不能简单乘6。

## D 美术与实机资源规划

继续大头短身、小脚豆、棕色粗线、平涂、短弯袖与握拳；六武器环绕、角色只有两只手。所有新兵一眼看出“盾／枪／弓／马／炮”，阵营靠头盔、布料、旗面变化，同类保留骨架。新英雄也要有待机眨眼／呼吸／小点头、方向行走、技能前摇／发力／收回、受击、胜利与哭泣失败图，不能只交一张笑脸。

地图继续宽高各1.5倍视野、草地小花和小桃树；卷主题通过草色、少量花瓣／地面纹样、出生符印和远景色变化，不增加挡路城楼、大船、巨石。大型器械和象视觉高度可约英雄1.3～1.6倍，伤害与碰撞仍按02规格，不把地图撑成杂物场。水战用登岸／火攻训练解释，不加本轮未设计的船只操控。

新效果身份：偃月刀青金宽刃波、画戟暗赤二段弧、银枪蓝白硬刺、连弩木弦与短箭尾迹、羽扇半透明风羽、太平要术黄符落印、七星灯暖金点阵。普通攻击不铺满全屏大圆；Boss大技能可以华丽，但危险预告边缘必须压在友方粒子之上，受击反馈仍短促、清脆，不回退夸张风声。

当前iOS战斗有过闪退，内容扩展必须受以下设计约束，待设备实机验收：

- 同屏普通敌80（首领入场可81）、敌箭80、友方投射物160、短命粒子280、较重特效36、金币128、回血物4；随从12、陷阱12、阵地8，各自硬上限。超过预算合并小粒子／低优先尾迹，**不能生成没画出的伤害弹**。
- 全部40种按章4～6类投放；美术采用十张紧凑共享图集一次加载，新增RGBA解码约14MiB，不按章反复加载大原图。
- UI四图集与单位六图集分为chronicle-ui/chronicle-units，两包均本地。source/prompt/manifest在art/runtime-v4，不把原始概念板搬进assets；没有CDN部署依赖。
- 图鉴12项分页，SpriteFrame共用同一小图集；只建立当前页节点和详情，关闭销毁UI，切帧缓存共用。未制作独立详情沙盘，不假称动态演示。
- 本AppID20MB预览限制、本地19.5MiB安全预算仍检查。采用透明切格＋RGB量化在保留alpha下减包；最终构建与服务端结果见07。若后续再超预算，遵循用户优先完成度指令，但不能不报告实际超限。
- iOS峰值纹理/系统内存、完整通卷和后台回归尚需设备验证，不用PNG字节或PC桩CPU推断iPhone性能。

## E 实装批次与验收边界

1. **基础层**：先做章节／快照／固定强度公式／图鉴数据结构与UI。全量条目可用文字和已定概念预览，尚缺动作时不能标“已可战斗”。不一次复制17段战斗脚本。
2. **首卷内容**：验证C01～03、张角／吕布／董卓；新兵先做朴刀、长枪、大盾、弩手、重骑、弩车六机制族。弩手／弩车在首卷图鉴先收录，真实首登仍遵守C04，不为了赶批次乱插教学。新武器先双股、偃月、蛇矛、画戟、七星、太平、银枪、羽扇；后两件通过新英雄自带，普通商店仍按03章节解锁。
3. **二、三卷**：完成袁军、曹魏、江东混编与弓弩／火攻身份，补官渡和赤壁Boss；把可换皮复用的骨架成本跑通。
4. **四至六卷**：重器械、南中、阵法和组合复习；按实测经济修正17章，不用超高弹速替代设计。
5. **通用技能**：12项已接入选人搭配、击杀充能和战斗；图鉴同源展示，不将技能当成商城被动出售。

验证矩阵覆盖五英雄×近战／远程／法术×单槽／三槽／六槽；至少有纯近战、机关枪、火场／随从及混搭四构筑到终章，记录取样数而非靠单次通关下结论。

- 战斗：普通兵理想处理约0.2～1.5秒、重装约2～5秒、Boss中位约35～60秒为首轮目标；如果六把强武器能打快可允许，但不应前期一把机关枪让全部Boss零施法。无强制锁血。
- 公平：新兵先教学再混编；全部有效伤害1心；前摇完整；六危险圈中Boss至少3位；不在人物脚下瞬刷，不出现无提示的大范围秒伤。
- 经济：记录每章收入、货架、购买、弃牌、刷新、升级与剩余钱；前15秒能买一把新武器，普通经济能在首卷成型；不要求每张全买或每轮刷新。
- 存档：交易原子、不双发Boss金、同货架恢复不改价不重抽、后台恢复／异常退出／死亡重试不复制装备与金币，旧单章存档需要版本迁移或提示保留历史成绩。
- 视觉：48～64大小图标仍认得刀枪弓扇；小兵／骑兵不同方向都有行走与出手；赵云／孔明失败用哭泣而非战斗笑脸；危险提示不被玩家大招遮住。
- 稳定：真机iOS进行完整一卷、后卷压力构筑、后台往返、打开关闭图鉴及多次重试；记录机型、系统、峰值内存和p95帧耗时。60帧档以16.7ms为目标、低档稳定30帧33.3ms为兜底；未经实机不能宣称“不会闪退”。
