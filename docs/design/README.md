# 桃园小英雄：当前战役与三国图鉴设计

当前版本 `chronicles-v7-seven-bosses`；本目录整理已实装的设计，历史版本由Git追溯。

数值与实际差异以[07实装和验证](07-implementation-and-validation.md)、源码和项目skill生成表为准；原提案中的远程分卷加载、图鉴收集成就等未实装项明确保留后续。

当前为**六卷七章/七位首领、40敌兵、36武器、5英雄、12个自由选择且击杀充能的通用技能**。七人各一场：张角→吕布→董卓→袁绍→曹操→孟获→司马懿。已按高饱和吕布样板接入21招及动作，不再保留另外七人或重复战役形态。

每章15秒整队→三段各30秒→Boss；章间购物、装备继承、普通兵持续援军。七章模型总战斗约17.1分钟，另加购物/重试；不是真人计时。五心、六槽环绕、移动自动攻击＋一个通用技能，首页开始始终新局、失败可重试本章。

## 核心取舍

- **有章节变化，不无限堆速度**：普通兵HP随章适度上涨，移速涨幅最多12%；冲锋速度、弹速、技能前摇不随流程缩短。难度依靠盾弩配合、骑兵、阵法、火攻与器械。
- **武器扩充保留身份**：偃月刀宽扫、画戟二段、银枪连刺、连弩穿透、羽扇推场、灯阵环身；品级不只变颜色。仍只有六槽，必须在覆盖、单体、控制和价格之间取舍。
- **先可成型，再有取舍**：首15秒仍只保底28金币买一把新武器；后期用家族权重和同款倾向防止36武器稀释池。商店可以全买，但金币有限。
- **五心继续简单**：任何有效攻击一心，普通兵与Boss共用保护；章末回一心，不章章自动回满。没有等级和经验条回流。
- **图鉴有数据，首页仍简洁**：首页只加小书本入口；敌兵、武器、技能三页能看标准值与章节值。技能列表与战斗同源，可在选人页自由搭配一个。
- **先控制资源再扩大内容**：40机制不同时出场，共享紧凑图集与受控主体Sprite；概念图留在art不进入微信包，必须守住既有预览与iOS内存预算。
