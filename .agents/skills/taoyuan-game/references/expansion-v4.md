# v4长线战役：当前实装

2026-11-13用户已授权“先创建素材，再实现代码”。本轮已完成本地素材、6卷17章、14位Boss/17场形态、40类兵种、36武器、5英雄、首页图鉴及schema4检查点。v5已按后续用户要求将24个通用技能全部接入战斗，选人自由选1个、击杀充能；不在商店销售。

## 当前流程

- 首章15秒第零段→收入补足28金币先补给→三波各30秒/波后补给→张角；Boss持续援军、入场不清旧兵或在途箭。
- Boss死后回收金币、回复1心、清旧章战场、进入下一章商店，构筑/金币/技能充能继承。出店15秒整队，结束直接进入30秒正式战段，不连续开两个商店。
- 17场依次：张角、吕布虎牢、董卓、袁术、吕布下邳、袁绍、夏侯惇、曹操长坂、周瑜、曹操赤壁、黄忠、马超、陆逊、祝融、孟获、司马懿祁山、司马懿五丈原。只有终章Boss死才通关。
- 首页五英雄均可直接选，分别默认草鞋/扁担/杀猪尖刀/龙胆银枪/白羽扇；无开局选武器。五心、六槽周身环绕、无经验/隐藏等级、左下固定摇杆/右下单通用技能按钮保持。

## 源码与固定平衡

`chronicles-data.ts`为40兵/17章/24技能数据，`chronicles.ts`为编组/预算/缩放/Boss动作表；`extra-weapons.ts`为25新增武器/四阶系数和机制文字；`CodexView.ts`只读UI，`chronicle-art.ts`加载共享小图集。

章节referenceDps固定为152.05/300/460/650/850/1100/1350/1650/2000/2300/2650/3000/3350/3600/3900/4150/4500。BossHP=referenceDps×40×固定个性系数；普通HP乘(reference/152.05)^.95和战段1/1.04/1.08（Boss新兵1.1）。威胁预算min(7.5,2.5+.3125×(章−1))，正式三段×.9/1/1.1、Boss×.85。不按当前装备动态加血，不靠后期无限提速。

普通兵80阈值、首领满场额外1位；远程同时4、冲锋同时2、器械2、象/狼骑各1；地面危险6，普通最多3。所有有效伤害1心，统一保护，危险判定与可见边界使用同一数据。Boss默认半血第3动作；孟获70%/35%换节奏，90秒后频率最多120%。

`docs/chronicle-balance.json`来自150条五英雄真实交易路径，假设65%清兵/65%命中、每店最多两次刷新。末章Boss理论中位约53秒，不等于真人胜率。`docs/performance-node.json`为Node桩CPU/绘图调用，不是iOS帧率。

## 素材、动作与包体

先用imagegen制作透明源图，prompt与hash在`art/runtime-v4`；`scripts/pack-chronicle-art.cjs`按连通轮廓切分、留6px安全边，导出10个紧凑图集。`assets/chronicle-ui`含英雄常态/哭脸、睁闭眼/短袍、新武器与技能图标；`chronicle-units`含14Boss、3骑将正背坐骑、40敌兵正背面。

实际使用共享小图集一次加载（新增RGBA解码约14MiB），不是按卷下载/CDN。素材已能控制在现有本地预算，无需部署远程资源；不把原始大概念板放进assets。新兵为正背图+头/躯干/双脚分层动作及镜像，有独立行走、后仰/短跨/出手，不宣称40套逐帧手绘动画。六卷共用草地，用躯干色调区分；八阵营整套换装仍是后续美术可扩展项。

`npm run assets:optimize`保留尺寸/逐像素alpha量化RGB；先pack再optimize，不能顺序反过来。新图集meta要提交。正式构建和微信服务端包体检验结果见07实装记录。

## 保存、失败与限制

`chronicle-save.ts` schema4；章入口、进店、每次购买/刷新/合成/出售、出店保存Run/位置/心/冷却/计时/货架。内部恢复可还原原货架价格和已购状态；当前首页不再读取旧快照，点击“开始”直接用所选英雄/技能开启第1章新局，不弹继续/重新开始选择，新局覆盖检查点；章内失败重试保留。不逐帧存敌兵。当前未保存战场随机种子，敌兵位置/顺序重采样，不能宣称逐帧重播。

死亡“重试本章”恢复章入口装备金币，不保留失败刷的收益；累计战斗时间/重试数保留。完整通关最好用时单独键taoyuan-chronicle-clear-best-v4；旧张角/无尽纪录不混用。首轮尚无独立“一命通卷”榜、卷末短战报、专属剧情对白或完整iOS通卷验收，不能把这些设计提案标为实装。
