# 分关挑战 v8：当前实现

用户已授权实施。正式入口已接入stage-v8.2-reinforcements；策划源为docs/stage-challenge-v8/方案.md，当前实现与验收见docs/stage-challenge-v8/实现说明.md。概念图不是实际引擎截图。

## 数据与入口

- stage-data.ts：6关/奖励/基础池/波时长/固定强度；stage-progress.ts：英雄个人通关、账号共享内容、发现和偏好；campaign.createStageRun统一校验正式入口。
- GameBootstrap：showMainMenu→createStageRun→startWave直接第1波→波末购物/resumeStage→endStage。stageBoundary要求第三波miniDefeated即过波，不设时间门槛；endStage不调用旧completeChapter。run.wave=2仅兼容自动战斗，真实波次stageWave=1…5，waveTime为该波模拟时长。
- CampaignView/StageViews：动态少年、三头像、初始武器方钮、技能圆钮、六关弹窗、四卡商店、首通奖励和已共享结算。初始武器变化同步展示持握，开局仅一个实例。

## v8.1 界面还原与黄巾三将

选关和当前关卡卡使用stage-jade.png九宫格手绘玉绿金边，来自内置image_gen，源图/提示在art/runtime-stage-ui；pack-stage-art将批准stage-picker概念中的大场景裁为缩略图，不能再换回几块平色。首页右卡有进度题签、场景图、关名/五波、两首领图标和更换关卡；选关3×2，大图/描金/选中辉光/未解锁锁标，朱红确认按钮与底部奖励分类。

黄巾三将采用既有E06造型、较小冠标和明确俯身/蹬地/冲出/刹停。yellow-chargers纯状态与CCD；yellow-charge-effects仅绘制本地预警、速度笔触/尘土，不画路径和范围框。3只每只2400，追击200，450内可蓄力.7秒，760速度冲.48秒（364.8距离），收招1.1秒；轮流起手，最多一只处于蓄力/冲锋，其他追击。锁向后不拐弯，可五秒眩晕，击退抗性不等于无敌。聚合血条固定7200并显示剩余只数；最后一只死才miniDefeated并回1心。精英残影与吕布残影分别缓存，跨兵种复用不能混尺寸。

## v8.2 出兵与中首领结算修订

第三波在全部中首领死亡后的模拟子步立即结束，购物前自动回收地面金币；不等待60秒，HUD只显示“击败小首领”。其他波结束条件不变。固定第三波赏金为25/30/35/40/45/50币（按关卡），加当波击杀所得与军饷道具加成；黄巾三将合计发一次并回1心，不能逐只重复计奖。

六关各波出兵成本速率倍率改为.75/.95/.60/1.20/1.20，较旧版分别+25%/+21.8%/+50%/+20%/+140%。黄巾成本速率为1.5/1.9/1.2/2.4/2.4每秒；实际每秒人数按兵种成本、配比、同屏余量决定。正式Boss召唤物不再增加普通刷兵时钟，仍共享80敌军与既有召唤上限；普通兵26+6×(关−1)人数、22+6×(关−1)成本上限保持，不能无限累积同屏对象。

第3波收入随击败速度变化，不保证旧60秒经济目标；固定收入购物模型仅用于负担对比，不证明实际金币、存活率或手机帧率。

五丈原每波加入E08戟卫近战补位，避免射手/骑兵/辅助配比同时触顶后无合法兵种可补而停兵；保留各兵种配比上限。
