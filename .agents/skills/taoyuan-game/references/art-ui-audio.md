# 画风、界面与声音

待审方向：[五英雄少年武将提案](../../../../art/concepts/hero-youth/README.md)。用户本轮仅要求设计图，当前运行形象/动画/头像不变；少年稿去胡须、年轻化脸型与发型，保留小脚豆和原武器。关羽淡朱红脸与小尺寸简化仍待评审，不能未经确认替换整套素材。

## 形象原则

搞笑三国，Q版动漫、小脚豆身体；大头、短躯干、极简小脚，夸张眉眼、表情和手臂。不是写实三国、长腿人形、像素画或华丽MMO。小尺寸仍应能看清表情、武器轮廓和面向。

| 角色 | 识别元素 | 默认武器与持握 |
| --- | --- | --- |
| 刘备 | 绿衣红腰带、发髻头带、粗眉、坏笑、腮红、小胡子 | 菜单画双手握住草鞋，不能提着鞋；战斗单武器投掷草鞋，装备多件时按实例分布 |
| 关羽 | 红脸、夸张长黑须、绿帽绿袍，严肃中带喜感 | 默认握扁担近战横扫；扁担为细长微弯竹担，不能画成擀面杖或继续投豆 |
| 张飞 | 炸毛黑发、浓胡子、大嘴笑/怒吼、紫衣红腰带 | 默认握细长传统杀猪尖刀；短木柄与尖刃清晰，不是方形菜刀，保持短小Q版体态 |
| 赵云 | 银甲蓝缨、英气歪眉、短袍小脚 | 默认龙胆银枪，蓝白硬刺与突进，不能长腿写实化 |
| 孔明 | 纶巾、白绿短袍、狡黠眼神 | 默认白羽扇，绿白风带与有限挡箭 |
| 黄巾步兵 | 和主角同一小脚豆比例，黄巾头带、短衣 | 随机镰刀或锄头，不能回退为史莱姆 |
| 黄巾弓兵 | 同阵营比例、弓箭轮廓清晰 | 代码ID为 `spearman`，当前表现实际是弓箭手，不是投矛手 |
| 黄巾骑兵 | 骑马、黄巾、身体前倾和蓄势动作 | 接近后冲锋，蹄步和尘土表现，不画冲锋路径/范围线 |
| 张角 | 道士、道冠法袍、持法器，夸张眉须 | 定点雷与三才雷阵，保留可读预警圈和较华丽的爆发 |

主角战斗头袍分层、真正睁闭眼切换；刘备轻晃头/连眨、关羽慢点头、张飞笑颤，手腕随呼吸轻摆。行走依据实际位移驱动交替脚步、躯干摇摆，顶墙不能原地跑；详情见[presentation-animation.md](presentation-animation.md)。旧敌兵保留逐帧图；v4敌兵/骑将正背面，头/躯干/双脚拆层驱动行走与攻击倾身，左右镜像，不只整图旋转。赵云轻挑眉点头、孔明缓眨与轻摇头，睁闭眼有独立素材。

## 武器与命中特效

单武器保留握持/自由手，不能出现第三条手臂。袖子短且弯，接在短袍低肩位置；掌心/拇指位于武器前，不能粗直杆横穿脸颊。遮挡与姿势见[手臂与握持](hero-arms.md)。两件及以上普通武器用稳定椭圆锚点环绕前后左右，不全堆手上；柄节点直接挂主角，不能挂到被隐藏的手臂下面。

飞剑单独绕圈：刚性清晰剑身、短青白切割弧、持续随角色移动，不能退回软追踪弹，也不能因弧绘制方向错误连成整圈强光。

普通命中偏克制：短线/小火花、闪白、形变、击退、伤害数字；不做遮住角色的大爆闪。命中与死亡各结算一次。爆炸半径和伤害范围一致；二次爆炸/分裂不递归。雷阵可以更华丽，但预警、爆发、余光必须可辨，预警与余光不造成额外命中。

普通受击闪白不是硬直；玩家保护期不复用受击红闪。代码中的 `weaponFreeze` 目前没有接入真正停顿，见已知差异，不能仅凭赋值宣称已有命中停帧。

v2.7技能与11武器采用有预算的程序粒子、短亮线和分层图形；具体外观、预算、生命周期与研究取舍见 `combat-effects.md`。普通命中短促，通用技能有独立剪影；友方地面表现不能盖住敌人预警圈。

v5.2除横扫六合外23项按已确认概念实装，以`skill-vfx-art.ts`程序轮廓建立独立身份，不把概念海报打包。水浪用圆润白沫卷冠、三纸兵有折盔/方袖/短弩，增益旗和桃心避开脸；双盾/收箭/纸兵姿态取真实状态，详见`combat-effects.md`与`docs/skill-vfx-v5.2.md`。小尺寸身份优先于海报细节，G03 A金锋回旋不重做。
