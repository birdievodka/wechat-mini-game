# 画风、界面与声音

## 形象原则

搞笑三国，Q版动漫、小脚豆身体；大头、短躯干、极简小脚，夸张眉眼、表情和手臂。不是写实三国、长腿人形、像素画或华丽MMO。小尺寸仍应能看清表情、武器轮廓和面向。

| 角色 | 识别元素 | 默认武器与持握 |
| --- | --- | --- |
| 刘备 | 绿衣红腰带、发髻头带、粗眉、坏笑、腮红、小胡子 | 菜单画双手握住草鞋，不能提着鞋；战斗单武器投掷草鞋，装备多件时按实例分布 |
| 关羽 | 红脸、夸张长黑须、绿帽绿袍，严肃中带喜感 | 默认握扁担近战横扫；扁担为细长微弯竹担，不能画成擀面杖或继续投豆 |
| 张飞 | 炸毛黑发、浓胡子、大嘴笑/怒吼、紫衣红腰带 | 默认握细长传统杀猪尖刀；短木柄与尖刃清晰，不是方形菜刀，保持短小Q版体态 |
| 黄巾步兵 | 和主角同一小脚豆比例，黄巾头带、短衣 | 随机镰刀或锄头，不能回退为史莱姆 |
| 黄巾弓兵 | 同阵营比例、弓箭轮廓清晰 | 代码ID为 `spearman`，当前表现实际是弓箭手，不是投矛手 |
| 黄巾骑兵 | 骑马、黄巾、身体前倾和蓄势动作 | 接近后冲锋，蹄步和尘土表现，不画冲锋路径/范围线 |
| 张角 | 道士、道冠法袍、持法器，夸张眉须 | 定点雷与三才雷阵，保留可读预警圈和较华丽的爆发 |

主角战斗头袍分层、真正睁闭眼切换；刘备轻晃头/连眨、关羽慢点头、张飞笑颤，手腕随呼吸轻摆。行走依据实际位移驱动交替脚步、躯干摇摆，顶墙不能原地跑；详情见[presentation-animation.md](presentation-animation.md)。敌兵有面向与行走/蓄力/攻击帧；左右通过镜像适配，不用单张图只倾斜代替动作。

## UI

横屏、手机优先、安全区留白。主基色：暖纸 `#fff0d2`、深墨棕 `#432d1d`、玉绿 `#355e40`、朱红 `#c94d2e`、金边 `#ffda83`。品质色来自 `weapons.ts`，不能颜色与品级错配。

- 选人：左上标识，正上“选择英雄”；三张大卡，各英雄只出现一次。选中卡橄榄绿 `#66703d`、金边与勾选、轻微抬起；未选深绿 `#374633`。只显示姓名及“均衡·控场 / 近战·横扫 / 近战·暴击”。底部水平居中唯一红色“开始”。
- 卡片参考330×410，横向中心−385/0/385；开始按钮中心0/−287，触控330×88。整体缩放 `min(1.08,(width−112)/1360,(height−90)/660)`。这些是当前实现基准，修改布局可以调整，但要重新验证常见横屏比例及微信胶囊/底部安全区。
- 战斗左上头像、姓名、五颗心、金币，不显示等级/经验条。底部六个武器格；长名可缩为突突枪/霰弹枪/火箭筒，首件武器首帧就显示。
- 左下固定方向摇杆，底座半径96、头半径36（较初版约放大25%），触摸半径140，中心距左/下165/160；松手保留底座，暂停/购物隐藏；右下技能圆钮及冷却，圆钮中心与左下摇杆中心水平对齐，共用joystickCenter的y（距底160）。右上暂停避开原生微信胶囊。
- 商店为半透明弹窗，能看见冻结战场。三张卡、价格/购买、已购入禁用态、六武器管理、道具背包、刷新费用、继续按钮。热身阶段标题“热身补给”，继续按钮“进入无尽”。
- 当前没有升级选择页；旧纸卡升级实现仍在代码里，不应无意重新接入。
- Loading使用已有 `assets/campaign/poster.jpg` 刘关张战斗合影，顶部对齐等比铺满，底部标题“桃园乱斗”、金边绿芯进度条和简短百分比；微信引擎前置启动画面也使用同图与同位置进度条。机制与模板见 `startup-loading.md`。
- 通关结算用开心hero-select立绘与“通关啦！”/胜章；失败结算为暗桃园背景、左侧大哭英雄、右侧暖纸战报、红色主按钮“再来一局”与浅色“返回选人”；三人专用3×2选人/哭泣图集 `assets/results/portraits.png`，不能复用菜单/战斗笑脸。版式与素材出处见 `result-screen.md`。

## 武器与命中特效

单武器保留握持/自由手，不能出现第三条手臂。袖子短且弯，接在短袍低肩位置；掌心/拇指位于武器前，不能粗直杆横穿脸颊。遮挡与姿势见[手臂与握持](hero-arms.md)。两件及以上普通武器用稳定椭圆锚点环绕前后左右，不全堆手上；柄节点直接挂主角，不能挂到被隐藏的手臂下面。

飞剑单独绕圈：刚性清晰剑身、短青白切割弧、持续随角色移动，不能退回软追踪弹，也不能因弧绘制方向错误连成整圈强光。

普通命中偏克制：短线/小火花、闪白、形变、击退、伤害数字；不做遮住角色的大爆闪。命中与死亡各结算一次。爆炸半径和伤害范围一致；二次爆炸/分裂不递归。雷阵可以更华丽，但预警、爆发、余光必须可辨，预警与余光不造成额外命中。

普通受击闪白不是硬直；玩家保护期不复用受击红闪。代码中的 `weaponFreeze` 目前没有接入真正停顿，见已知差异，不能仅凭赋值宣称已有命中停帧。

v2.7技能与11武器采用有预算的程序粒子、短亮线和分层图形；具体外观、预算、生命周期与研究取舍见 `combat-effects.md`。普通命中短促，英雄技能有独立剪影；友方地面表现不能盖住敌人预警圈。

## 声音

- 草鞋使用已确认的 `assets/battle/audio/sandal-hit-pcm.wav`；只要“啪”的实际命中声，不加挥鞋风声。不要重新依赖用户Downloads路径。
- `assets/sfx` 有豆粒、桃枝、刀、杖、爆竹共10个生成片段；连同草鞋为11个声源。11种武器有映射，但后六种复用现有音色，不是每把都有新录音。
- 由 `weapon-sound.ts` 定义攻/命中路由、音量、同声限频、命中优先、最多6音效声道。不要用每帧新建音频或每弹都重置同一声音。
- BGM为 `assets/music/taoyuan-kaida.wav`，60秒循环，音量0.26，0.45秒渐入；方向为轻松搞笑中有战斗节奏。用户手势解锁、独立音乐/音效开关、购物持续播放，音乐时钟独立于战斗；手动暂停/后台暂停、恢复接续（回到商店自动续播）。

武器v3.1替换图位于presentation的weapon-revision（扁担（单瓣图不再用作持握图标））与butcher-knife（尖刀）。选人/结算上排常态下排哭泣统一新默认武器；Loading及菜单背景海报也已替换扁担/尖刀。原提示词/未修改源图见 `art/concepts/weapons-v3.1/`，具体升阶与防重复命中见[武器升阶规则](weapon-evolution.md)。

v3.3桃花枝恢复原icons花枝图和程序持握花枝，发射物仍是花瓣。通关和失败共用纸卡布局但表情、标题与印章必须不同，见[结算页](result-screen.md)。
