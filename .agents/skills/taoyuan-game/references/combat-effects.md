# 战斗特效与粒子

v2.7以当前小脚豆/纸墨Q版为基准，使用短亮线、形状鲜明的剪影、少量散落物和分层冲击。v3.1同时按武器升阶规则更新攻击数量/范围；敌人曲线保持现有规则。旧v2.7构图仅作历史参考。

构图样张：`art/reviews/combat-v2.7/particle-contact-sheet.png`。使用当前程序特效绘制命令在Canvas2D中抽帧，展示三技能4个时间点及11武器；不含人物/敌人，不是微信实机截图。后续视觉变更应重新核对，不能以样张代替实际场景验证。

其他agent进行特效设计与实现时，按[独立Cocos特效skill](../../cocos-game-vfx/SKILL.md)工作；通用设计/实施/验收流程在那里维护，本参考继续记录项目当前表现与预算。只读检查脚本可从实际代码提取技能定义、池上限和集成位置，不将历史案例数值当作新技能默认值。

## 渲染方案

研究了 [Cocos 3.8 ParticleSystem2D](https://docs.cocos.com/creator/3.8/manual/en/particle-system/2d-particle/2d-particle.html) 的发射率、最大粒子、寿命和位置类型，以及 [2D合批规则](https://docs.cocos.com/creator/3.8/manual/en/ui-system/components/engine/ui-batch.html)。原生二维粒子适合贴图发射器；当前已裁剪引擎、图形画风和多种定向形状下，选用程序二维粒子池。v4.3保留280槽物理与发射预算，改由ParticleSprites的固定可复用四边形显示，6种形状共用运行时96×64抗锯齿白色mask（24KiB），共享默认Sprite材质，不额外启用粒子引擎模块。复杂冲击/雷阵/切割弧继续用共享Graphics层；不能宣称GPU粒子或零Draw Call。

- `combat-particles.ts`：280个预分配对象，普通粒子只用前200，余80预留高优先级；普通发射每秒360、瞬发令牌72。满载减普通碎屑，技能可覆盖普通粒子，不能覆盖同优先级技能粒子。
- `combat-effects.ts`：36个复用表现槽，普通占前28，余8留给高优先级。三英雄表现优先级3，技能追加爆炸/技能粒子2，普通命中与枪火1，尾迹0。
- 粒子是火花、花瓣、豆粒、烟尘、碎片、星芒；速度、阻尼、重力、旋转、透明度随寿命变化，最长为短暂余光，不留满地图亮斑。
- 专用随机数与游戏随机数隔离，不能因喷更多粒子改变暴击、掉落或出兵序列。
- 友方地面层在人物下，亮线/少量碎屑在上；敌方预警与雷阵最终保持在友方表现上。跟世界/相机走，HUD/摇杆不抖动。
- 模拟子步进推进粒子；绘制只读，购物/暂停/后台/准备倒数均冻结；退出/死亡/重开清池。屏幕外粒子和表现不提交图形，投射物池仍为原160上限。
- 有限容量只限制视觉，不得用粒子是否发射成功决定伤害、命中或技能释放。

## 11武器视觉身份

| 草鞋 | 旋转鞋身，暖白短掠线，少量草金纤维尾屑 | 短促金白拍击星点、定向碎屑；沿用啪声，无挥鞋风声 |
| 扁担 | 更宽暖金横扫月牙，随真实攻击角度扩大 | 木色碎片与尘点、强击退，不飞出本体 |

| 杀猪尖刀 | 扇形锐利切割月牙、白色刃线 | 白金火花，短促有方向，不扔刀 |
| 爆竹 | 引线火星、短暖白尾迹 | 橙金爆点、短焰星与少量散烟，范围与实际半径一致 |
| 突突枪 | 快速枪口闪、细金白曳光、少量弹壳 | 小而快的命中火花，不铺大白闪 |
| 霰弹枪 | 较宽枪口喷发、五弹各自短尾迹 | 沿各自命中方向的金色碎屑，射击批次仍最多4弹中同敌 |
| 火箭筒 | 定向弹头，橙白喷焰、短烟尾；不能让弹头随时间原地转圈 | 按真实范围的火环、焰星、少量烟尘，白热中心迅速消退 |
| 青莲飞剑 | 持续刚性旋转剑阵、三层短青白切割弧、剑尖星点 | 青色命中锋芒，仍共享每武器对同敌冷却；不能画整圈高亮光环 |
| 五雷符 | 紫白分叉折线、边缘淡光、短支流 | 落点电星；保留实际连锁顺序，不把直线光束当额外伤害 |
| 吞天葫芦 | 葫芦口三股旋转涡流、短寿命螺旋吸流、沿敌人到葫芦方向移动的光点 | 紫色小亮芯；仍6段、每段最多6目标，不增拉扯距离或伤害 |

枪弹/花瓣的方向始终跟实际弹道；只有草鞋自旋、花弹/爆竹保留装饰转动。弹射改向后同步弹头朝向。

## 三英雄技能（v4历史原型，v5已移出战斗入口）

当前24通用技能的机制和特效来自CommonSkillRuntime/CommonSkillEffects，见[通用技能](common-skills.md)。以下专属表现不再绑定英雄。

- **刘备·以德服人**：金色双圈冲击、八向草鞋掌印向外拍开、上方短暂大鞋印、金屑星芒。圆周打击与短无敌/加速仍按原判定；角色脸部留白。
- **关羽·横扫千军**：沿自动选定扇区冲出扁担青金龙形横扫波，三股盘绕青绿丝带、亮色扇刃与木色碎屑，龙形冲击头用眼/角/须形成识别轮廓。扇区±0.655弧度，距离与技能定义一致。
- **张飞·桃园狮吼**：紫墨锯齿狮面、眉眼与张嘴剪影、三层桃粉震波、外散花瓣。0.35秒后追加两处实判桃花爆散；主爆与追加分开表现。

技能约0.72–0.8秒结束，不做全屏蒙白、长镜头停顿或额外技能文字遮住战场。普通命中比技能更小、更短，金/青/桃粉与张角金红危险圈区分。

## 验证与调整

先验证真实攻击/释放是否接入，再看池容量、暂停、镜头、清理和多武器负载。三技能不可只换颜色；所有武器都要有对应视觉，预算紧张时保留弹体、范围和技能剪影，优先减少尾屑。程序池上限是防失控门槛，不等于已证实所有手机稳60帧；交付明确模拟器与手机实测范围。

## v3.4 性能约定

不改上述形状和伤害，矢量袖子/剑阵等仅每显示帧最后一物理子步重绘；静态拳头/弹体缓存，隐藏/空图层不反复clear。只在内存告警后暂停15秒装饰尾屑，保留技能粒子/核心命中/危险提示；常态预算不降低。说明和验证见[性能与稳定性](performance.md)。

## v4名器与两位新英雄

36武器共享原有280粒子/36表现，不另开25套发射器；v4.3的粒子节点只有固定280个槽位且按需创建/复用。偃月刀青金宽刃、画戟赤色二段、银枪蓝白硬刺、金属刀剑暖白窄锋、木弩短箭尾、火油橙烟、震天雷爆点、羽扇绿白风线、符书金雷、灯阵金星、八阵青线、木牛机关曳光。出手/追加段/直击/持续场分别调用，装饰不加伤。

赵云技能蓝白枪势与3道收束硬刺，真实330位移与路径宽100；孔明绿色扇形风带/白羽，420/120°与真实判定相同，三片有限防箭。Boss危险圈/火扇/线区/有缺口火环统一由EnemyZone驱动警告和伤害；周瑜火环内侧与缺口是真安全区。所有敌方危险边缘压在友方粒子上，UI不震。


## v4.3密集战斗优化

ParticleSprites保留原火花/花瓣/豆粒/烟尘/碎片/星芒、寿命、旋转、颜色和淡出，屏外隐藏而不改粒子物理。普通碎屑和英雄技能均复用同一24KiB贴图，死亡/清场立即隐藏，组件销毁释放纹理与帧。复杂技能、敌方危险范围仍在原共享Graphics层，危险提示压在粒子层之上。

BattleSpriteAtlas启动时用Canvas2D适配器烘焙既有drawWeaponArt(projectile=true)与金币/阴影/出生环、6类敌弹；不是生成新画风。1024×768 RGBA约3MiB，按alpha实测紧裁并保存握点偏移，避免透明大四边形过度绘制。金币、飞剑本体、双方弹体和出生环复用Sprite；切换弹体种类只换帧，不销毁重建节点。平台没有2D Canvas或烘焙异常时回退原矢量路径。剑阵三层切割弧预计算单位路径，不删弧/星点；新兵分层尺寸和受击/阵营色仅在变化时更新。


v5技能表现最多32个共享层Visual和原280粒子，不为24技能各建Graphics或新发射器；时间/任务只在物理模拟推进。水浪按可见扩散半径命中、八门阵进入一次、雷火星落按排程落点/半径结算，箭线在明确窄路径内命中；头上旗帜/纸兵/护盾跟随人物，替身与阵地固定世界坐标。

## v5.1 横扫六合 A金锋回旋

用户确认A版，替换旧细环和六箭头。`sweep-effects.ts`预计算48段带首尾收尖的月牙轮廓，共享四个坐标缓冲；赭金背沿、实体金刃、较宽暖白刃面与细锋边构成主刀光，内侧两个低透明拖尾和短笔触随顺时针转动。后半绘在人物下，前半绘在人物上；交接处同透明度，不能出现硬接缝。世界顶视角保持半径250，不照搬概念稿的透视椭圆改变判定边界。

命中仍在原Runtime面积判定里一次结算，每个有效目标追加一个0.19秒小型三叉楔形接触闪和6枚定向粒子；空放不伪造火花。主刀光14枚切向细屑、主体0.4秒结束，沿用32视觉/280粒子池与原共享层，不新增贴图、独立节点或发射器。最多10敌的接触表现加主体为11个Visual；池满只影响装饰，不能影响伤害。

共通角色动作只叠加短暂躯干扭转、头部反向小摆与轻微压身，不移动角色、不改变朝向和武器判定，不增加手臂。首个真实命中触发0.035秒、亚像素幅度的既有战场震动；HUD不震、没有全屏白闪或实际停帧。0.80S、击退300、基础22击杀及范围/目标数保持，伤害不依赖刀光层数和粒子是否成功发射。
