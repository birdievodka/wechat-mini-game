# 12通用技能：当前实装（v6.2）

五英雄自由携带1个，12项全部开放，按powerRank综合威力排序；威力阶重排为I～VI，每阶两项，非严格单体DPS。统一数据在chronicles-data.ts，合法性与充能在common-skills.ts，UI不可另抄数值。精确数据见[数值目录](balance-tables.md)，详细机制与新表现见[当前技能表](../../../../docs/common-skills.md)。

## 删除与迁移

本轮删除G05金蝉脱壳，连同此前G06声东击西、G14纸甲成兵、G23虎啸山林。连同此前G02/G04/G09/G11/G13/G15/G16/G17/G21/G24，均不可选择或直接施法。旧存档整备点/章节入口中的被删ID改为G01并就绪，schema4不变。正常保留ID不改充能。

保留旧ID和原图集格位。新G25护体剑阵icon24、G26震军号令icon25由BattleSpriteAtlas启动烘焙到原1024×768缓存剩余两格，artFrames用独立SpriteFrame副本引用同纹理，无新图片分包。图鉴详情按ID找数据，不能用icon作数组下标。选择/图鉴/演武共12项，单页显示。

## 综合强度排序

从弱到强：百步穿杨→冲锋破阵→横扫六合→八门金锁→火烧连营→水淹七军→星落五丈原→背水一战→护体剑阵→震军号令→雷霆万钧→万箭齐发。前两项I级，依次每两项一档，最高VI。

依据当前用户指定的强度定位：雷霆万钧、万箭齐发为VI最高档；护体剑阵、震军号令为V；星落五丈原、背水一战为IV。其余I～III保持。排序不是所有场景的严格DPS或实测胜率。背水一战本轮改为攻击频率×5（+400%），持续5秒；其余伤害/范围/时长/击杀需求/图标ID不变，充能费用独立于威力排序。G03仍第3/II级，原基线不动。

## 充能与演武

正式开局就绪，成功释放归零；每击杀真实小兵+1，不含Boss、中立物、召唤物。时间不回充、不存第二发。孔明.1与F08效率相加，需求max(ceil(基础×.55),ceil(基础/(1+效率)))。演武免冷却免充能，允许连放；重复增益刷新、控制取更晚结束时间；同技能火线/箭雨/八门/水浪替换上次场地与任务，不叠加巨大几何。
