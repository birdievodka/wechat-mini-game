# 演武场（v9.2.1受击反馈）

首页右下“演武场”为用户明确要求的新入口，和左下图鉴、中央正式开始并列；取当前所选英雄和通用技能，进入独立沙盒。旧随机测试入口仍不恢复。

- 进入即打开半透明配置面板。五页为小兵/Boss/武器/主动技能/英雄形态，内容列表每页最多12项，复用当前图鉴素材，不新增运行贴图。
- 全40小兵、7场Boss形态均可选择，数量1–80，−10/−1/+1/+10及1/5/10/20快捷数量。在场敌军（含Boss/召唤物）总上限80；超额请求只加入剩余容量并提示实际数量。角色可正常移动、自动攻击，保留出生动画和真实攻击/范围。
- 每个Boss实例保存encounterChapter；血量、外观和动作表使用自身章节，同时加入吕布/张角/司马懿等不能串招。召唤物继承来源章节；来源结束仍按原危险池清理。危险区6、敌箭80等性能预算维持。
- 36武器全部开放，四品级、六槽，不消耗金币；点槽再装配，已有槽替换、空槽顺序装入，同款可多把。至少保留一把（当前statsFor依赖首武器），可卸下多余武器；同步真实武器/剑阵/随从实例，不让被替换武器留永久伤害。
- 12通用技能按综合威力升序，任意装配，仍只携带一个。演武场免冷却、免击杀充能：释放后保持就绪，可立即再次点击；HUD显示“无冷却”，配置页也明确该规则。“重置技能”清除正在持续的效果与任务。暂停/后台/配置仍禁止施法，目标与伤害预算保留。正式闯关释放后归零、击杀充能不变。
- 无限生命仅跳过扣血，playerHp/run.hearts保持正有限值（随演武成长上限），HUD“生命∞”；仍正常触发受击闪红/退闪、−1飘字、击退/推开近敌、微震与原命中音。按正式1.2秒保护避免连续每帧受击；盾、冲刺无敌和格挡仍生效，不用Infinity序列化。演武不计正式时间、不随机刷兵/中立物、不进商店或结算、不推进章节。
- 面板冻结模拟并清输入，触摸/键盘/技能不能穿透；音乐继续。后台仍暂停，返回配置保持面板并恢复音乐。收起后显示左上状态与暂停、左下固定摇杆、右下技能、右侧“演武配置”。
- “清空战场”回收敌军、双方弹体、危险区、出生标记和临时技能表现，保留装备；可随时继续添加。
- 运行使用独立trainingMode，复用testMode只用于阻止正式计时/存档；不覆写正式检查点、最高纪录和通关成绩。退出恢复首页，正式“开始”仍新开所选合法关/个人成长满心/白I本命。

入口：CampaignView.menu → GameBootstrap.startTraining/openTrainingPanel；界面TrainingView.ts；生成/装备只走受演武模式保护的方法。test-training覆盖12技能零击杀连续释放、正式充能恢复、重置效果、界面操作、40兵/7场Boss、36×4武器/12技能、数量边界、混合Boss、长期无随机刷兵/商店、不死但有受击反馈、后台与正式存档隔离、退出后正式受伤恢复。

v7Boss分页只显示七位，均使用各自21招、真实正背动作和可拆召唤；普通兵/首领/召唤共用原容量，Boss死不推进正式征程，所有新任务/材质在清场和退出回收。主动技能仍无冷却。

v8正式页只允许小刘/小关/小张作为演武主角；赵云/孔明资产保留但不显示头像。演武仍可自由配全部武器/技能/敌军，不受共享解锁或未知图鉴限制，且不写发现/奖励/正式记录。

配置页顶端“英雄形态”快捷按钮及同名第五页直接选择小刘/小关/小张和0–6阶段，不再循环点击成长计数。七阶段为初始少年/本命进阶/获得坐骑/本命三连/骑乘冲刺/短甲与灵宠/桃园留名；右侧复用HeroShowcase动态预览、显示当前阶段收益并明确“应用此形态”。只预览不改变战场；应用后替换第一槽为对应本命/基础武器、保留该槽品级和其余五槽、敌军/位置/数量不变。同步真实头身/头像/姓名、心数、坐骑+30%、三连、冲刺和宠物，回满演武心数并清除旧技能/冲刺/宠物任务和在途友弹，技能恢复就绪。5/6阶段首次准备宠物资源成功后原子应用，失败/退出不留下半套形态。此为演武快照，不记录首通／共享发现；退出恢复进入演武前备战所选英雄/武器/技能，不能把演武中换英雄写成新的正式偏好。预览只在前台未暂停配置中更新，收起销毁整个预览子树及引用。Q/Shift冲刺在演武免冷却，Space/E通用仍免充能；退出演武正式入口重新按profile派生，不能继承测试成长。
