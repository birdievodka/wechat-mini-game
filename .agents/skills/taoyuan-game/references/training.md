# 演武场（v5.4.1）

首页右下“演武场”为用户明确要求的新入口，和左下图鉴、中央正式开始并列；取当前所选英雄和通用技能，进入独立沙盒。旧随机测试入口仍不恢复。

- 进入即打开半透明配置面板。四页为小兵/Boss/武器/主动技能，每页12项分页，复用当前图鉴素材，不新增运行贴图。
- 全40小兵、7场Boss形态均可选择，数量1–80，−10/−1/+1/+10及1/5/10/20快捷数量。在场敌军（含Boss/召唤物）总上限80；超额请求只加入剩余容量并提示实际数量。角色可正常移动、自动攻击，保留出生动画和真实攻击/范围。
- 每个Boss实例保存encounterChapter；血量、外观和动作表使用自身章节，同时加入吕布/张角/司马懿等不能串招。召唤物继承来源章节；来源结束仍按原危险池清理。危险区6、敌箭80等性能预算维持。
- 36武器全部开放，四品级、六槽，不消耗金币；点槽再装配，已有槽替换、空槽顺序装入，同款可多把。至少保留一把（当前statsFor依赖首武器），可卸下多余武器；同步真实武器/剑阵/随从实例，不让被替换武器留永久伤害。
- 12通用技能按综合威力升序，任意装配，仍只携带一个。演武场免冷却、免击杀充能：释放后保持就绪，可立即再次点击；HUD显示“无冷却”，配置页也明确该规则。“重置技能”清除正在持续的效果与任务。暂停/后台/配置仍禁止施法，目标与伤害预算保留。正式闯关释放后归零、击杀充能不变。
- 无限生命通过hurtPlayer入口免伤实现，存储的hearts保持有限值5，HUD“生命∞”；盾仍可消耗次数，不用Infinity序列化，也不产生永久红闪。演武不计正式时间、不随机刷兵/中立物、不进商店或结算、不推进章节。
- 面板冻结模拟并清输入，触摸/键盘/技能不能穿透；音乐继续。后台仍暂停，返回配置保持面板并恢复音乐。收起后显示左上状态与暂停、左下固定摇杆、右下技能、右侧“演武配置”。
- “清空战场”回收敌军、双方弹体、危险区、出生标记和临时技能表现，保留装备；可随时继续添加。
- 运行使用独立trainingMode，复用testMode只用于阻止正式计时/存档；不覆写正式检查点、最高纪录和通关成绩。退出恢复首页，正式“开始”仍新开第1章/五心/默认白武器。

入口：CampaignView.menu → GameBootstrap.startTraining/openTrainingPanel；界面TrainingView.ts；生成/装备只走受演武模式保护的方法。test-training覆盖12技能零击杀连续释放、正式充能恢复、重置效果、界面操作、40兵/7场Boss、36×4武器/12技能、数量边界、混合Boss、长期无随机刷兵/商店、免伤、后台与正式存档隔离、退出后正式受伤恢复。

v7Boss分页只显示七位，均使用各自21招、真实正背动作和可拆召唤；普通兵/首领/召唤共用原容量，Boss死不推进正式征程，所有新任务/材质在清场和退出回收。主动技能仍无冷却。
