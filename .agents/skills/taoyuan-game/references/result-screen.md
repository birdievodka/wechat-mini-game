## 状态与表现

- 第7章司马懿被击败且bossEncounter为真时总胜利；前16章进入下一章补给。显示“通关啦！”、hero-select-英雄的开心立绘、“胜”章，短促轻摆；不能复用失败哭脸或泪滴降级。
- 五心归零失败，显示“这把，先撤了！”、result-英雄的哭泣立绘、“败”章与轻微抽泣；不能复用开心肖像。
- 两种状态共用暗桃园/左英雄/右暖纸战报/朱红失败“重试本章”/通关“再来一局”与次要“返回选人”。导航同一结算只提交一次，防连点。
- 暖纸卡主数字：第零章失败为实际坚持秒数，正式战斗为所有章节累计战斗秒数run.elapsed（含失败尝试）；通关标签“通关用时”，其他为“本局坚持”。购物、后台、倒数不计入。
- 三项统计为击败敌兵、最快通关（胜利）或到达章节n/17（失败）、剩余铜钱。金币取run.gold，不标累计收入。
- 最快通关独立存taoyuan-chronicle-clear-best-v7，取较短值，首次/更快标记“刷新通关纪录”。不改旧无尽taoyuan-survival-best，也不在失败写通关纪录。
- 六格使用36武器统一手绘图标、品质边框/角标，空格横线；道具显示种数、重试显示次数。
