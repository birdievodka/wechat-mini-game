# 首章：第零段与张角（v4）

首章是17章征程入口，张角击败后进入吕布·虎牢，不再立即总通关；完整流程见expansion-v4.md。

## 阶段

15秒第零段→普通补给→三波各30秒（波后补给）→第三波天命/普通补给→张角。首章第零段仅E01 HP6/速度86，首次3兵、1.6秒尝试/上限12；结束金币回收并补收入差到28、回满5心。初次货架同款+可负担新类型武器+被动，不自动送装备。

Run.wave=1仅兼容表示第零段，2表示正式；wavesCleared为0～3，bossEncounter独立。HUD不显示进入第几波，补给统一“继续战斗”。角色、镜头、现存敌军、弹幕、地图保留。30/60/90秒边界截断模拟才购物；首领入场不清兵，援军继续，商店不停止BGM。

张角固定HP6082/移速62。单雷R76/0.85秒预告/CD2.6，三才雷阵3圈R70/0.85秒预告、逐圈错开.16秒/CD6；半血主雷间隔2秒。雷阵位置锁定，显示圈与实际判定一致；余光不伤。只有有效攻击扣1心，共用保护。Boss仅6%击退，已承诺施法不中断。

普通编组逐段开放E01/E11弓手/E19轻骑/E39道士，E39首章最多一位。正式生命按标准值和段倍率，预算2.5×.9/1/1.1，Boss×.85，不沿用旧无限时间指数曲线。敌军80存活阈值、满场首领可额外1位；Boss战没有定时自动胜利/额外首领/定时商店。

张角死时同帧阻止追加敌伤；回收金币、回血1、清旧章战场、打开第2章商店。出店构筑继承，再整队15秒直接正式开战。仅第17章Boss死才victory。

## 武器与前期货架

旧11种基础伤害为草鞋16、扁担32、桃花枝26、尖刀18、爆竹42、突突枪5、霰弹每颗8、火箭78、飞剑16、雷符46、葫芦每段5。完整品质见weapon-evolution/weapon-catalog。

旧扁担/尖刀在挥击20%～70%持续检测可见扇区，所有合法目标全伤，同挥Set去重；中途进入可受伤。新多刺/追斩在各子段时间点分别扫区结算，不宣称同一持续窗口；各子段系数及整组上限见extra-weapons。

桃花枝仍原分叉花枝，I单片、II起3花瓣；直击/爆散共享同敌一次，不新增“单片桃花”持握物。传统尖刀细长尖刃，禁止方菜刀。第一武器首帧即显示栏位。

首章15秒收入保底28，仅够一件默认白武器；超额工程金币不没收。首卷普通补给至少1武器，80%第二武器；飞剑/雷符正式30秒、火箭/葫芦60秒开池，30～60秒蓝25%、60秒起50%。默认赵云/孔明也有28同款及可负担新类型，不被普通解锁挡住。

首章经济/原地衔接/音乐/保留兵箭/首领唯一性持续出兵/同帧防反杀均在test-campaign；完整17章状态流转在test-chronicles。工程夹具强制推进边界和击杀Boss，只证明状态完整性，不是真人通关成绩。最新验收范围见docs/design/07-implementation-and-validation.md。
