# 首章：三波与张角 v3.3

当前可玩内容仅到张角，击败立即通关；没有后续第四波、第二首领或无尽延长。每3波出首领的规则由bossDue/BOSS_EVERY_WAVES表达，未来扩展另做内容，不预先开放。

## 阶段与计时

20秒热身→热身商店→第1波30秒→补给→第2波30秒→补给→第3波30秒→张角战前补给（天命/普通）→张角首领战→通关/失败。热身不计入3波。准备倒数、购物、暂停和后台不计战斗时间。

Run.wave仍以1表示热身、2表示正式战斗，属于兼容字段，不是实际第几波；wavesCleared表示已守0–3波，bossEncounter表示首领阶段。HUD显示“第n波/3”及剩余秒数，首领阶段显示“首领战·张角”。不能据旧wave=2文档恢复无尽。

30/60/90秒边界精确截断模拟后展示商店，继续才推进。第三波补给后点击“挑战张角”：生成唯一张角、停止新增普通兵与后续定时补给，保留存活小兵及原有敌方箭/雷圈；英雄位置、镜头、装备与中立物保留。不因首领存活超过30秒自动跳关或叠加另一个首领。

击败张角产生待结算胜利，阻止同帧追加敌伤，结束本次模拟即切victory；技能在帧外击杀时，在下一update计时之前完成结算。结算后不再计时/出兵/伤害。五心归零仍defeat。再来一局重新热身、0波、非首领状态与默认一件武器；返回选人保留英雄选择。

I–IV成长沿用weapon-evolution表。近战在挥击进度20%–70%持续检测整个可见扇区，与敌军躯体圆相交即命中，全部合法目标全额伤害，不设目标数量上限。同一武器一次挥击以hit Set去重；中途走入仍受伤、出生预告/收招不造成隐藏伤害。slash效果/出手声每次挥击一次，命中音首次真正打中时一次，不能因为每个子步检查重复刷音和特效。

sectorHitsCircle用有限扇区与敌人体积的最近距离判断，覆盖触及射程边缘/侧边的目标，排除外角之外及身后；源点与表现一致为英雄x/y+16。扁担/尖刀本体仍持握，不变成投射物。

桃花枝是原武器：手持花枝、UI为原分叉桃花枝图，发射单片花瓣。I发1片，II起3片；同轮扇射的直击/爆散对同一敌人仍合计最多1次，避免伤害因弹数失控。不是新增“单瓣本体”武器。

首个张角基础生命4200，90秒入场按当时倍率取整，约6082；出生后不随时间/玩家装备追溯补血。保持原落雷与三才雷阵，存活小兵继续参与首领战，但不再补刷小兵。

## 前期货架

热身商店固定2件武器＋1件道具（首次首件为默认同款）。正式前90秒普通商店保证至少1件武器/升阶，80%概率第二件也是武器；刷新保持此概率。三格可全买，武器最多6位，合成/出售/满槽替换规则保持。

30秒前白色；30–60秒25%蓝色；60秒起50%蓝色。飞剑/雷符30秒解锁，火箭/葫芦60秒解锁，确保首章内能买到全部11种武器。unlockedWeapons统一满槽与空槽路径，不能恢复120秒门槛把武器锁在本版可玩流程之外。第三波默认为天命页，可切普通武器货架，继续按钮始终为“挑战张角”。

## 结算与证据

通关显示开心立绘、“通关啦！”、“胜”章、通关用时/击败/最快通关/剩余金币/六武器；失败保留哭泣立绘和败章，显示已守波数。挑战用时包含实际20秒热身和正式战斗时间，不含暂停/购物。最快通关独立存taoyuan-clear-best，取较短值；不覆盖旧无尽纪录。

自动回归包含16敌全额横扫/晚入目标/躯体边界/同挥去重、三波与首领唯一性/长战不续波、三英雄胜利立绘与同帧防反杀/结算冻结/重开；1000轮验证前期约80%第二武器，100轮热身保证2武器。数值模型由scripts/report-balance.cjs重算，不把理论DPS或工程通关夹具当真人成绩。

## v3.3.1 连续战场与音乐

挑战张角时不清场：小兵的生命、位置、行动/攻击阶段和在途弹幕均延续，张角加入同一战场；保留补给结束的准备倒数和独立免伤。热身/普通/天命商店均冻结战斗但持续播放BGM，音乐时钟在商店和准备倒数独立推进；切后台暂停，回到商店自动接续，手动暂停战斗仍需点击继续。菜单/结算停止，音乐关闭设置始终生效。
