# 玩法与状态边界 v8

正式流程与完整规则见[分关挑战](stage-challenge-proposal.md)，精确内容与数值见stage-data.ts和生成目录。不要把campaign.ts的旧热身/升级函数或chronicles的七章兼容曲线当作正式入口。

## 流程与生存

选择小刘/小关/小张→个人已开放关卡→基础武器（已成长则个人固定本命）与共享已解锁技能→直接战斗（28币保留到波末）→五波45/45/小Boss全灭/60秒与大Boss→单关结算。第3波小Boss全灭立即结束，其他普通波到时购物；第5波杀Boss才胜利。普通兵与在途攻击保留到波间/入Boss，购物冻结、BGM持续，出店准备1.2秒；只小Boss死回1心，其他波不回满。整关死亡重试全新构筑，不带失败所得，也不回第一关。关间不继承任何当局装备、被动、增益、金币、充能。

基础小刘5心/300速度/1.0武器频率，小关5心/345/.85，小张6心/270/1.15；每英雄仅前两关首通各+1心、骑乘基础速度+30%。一次有效伤害扣1心，碰撞和受击无敌一致；有个人首通永久生命增长；无自然回血或经验/等级。所有回血上限/结算空心/存档校验读取heroMaxHearts，不能把小张裁成5。

真实受击使用hurtTime=1.2+道具加成，扣心/闪红/击退/音效；protectionTime用于开店后保护，不能闪红或复用旧扣血。大Boss致死命中置victoryPending后阻断同帧敌伤。

## 操作与时钟

左下固定摇杆：距左165/底160、底座96、头36、激活140、最大位移60、6%死区、80%行程到全速、模拟量响应0.7幂；摇杆头独立跟随实际指位。电脑方向键/WASD，Space/E技能；斜向等速、松手停止、失焦清输入。摇杆只接首个合法触点，技能手指不抢占；购物隐藏战斗HUD，倒数可提前按住但不提前模拟。右下技能与摇杆水平对齐。

仅battle/非暂停/非后台/非演武配置时推进模拟，每帧最多.08秒，拆1/120秒；购物、准备、后台不计波时长与成绩。run.wave=2是兼容字段，正式波次读stageWave，不能由wave===1走旧15秒热身。

普通/骑兵/Boss出生.9/1.1/1.5秒，前32%只标记，其后真实形象渐显；出生期无伤害/攻击。复用先清旧Sprite与身份，首次显形到完成不换兵种。可见且出生完成才记正式图鉴发现；屏外/后台排队/演武不记。

小桃树约82×86、首次8–12秒、之后40–60秒、最多两棵/寿命35秒；动物鸡兔猪首次25–40秒，之后45–65秒，最多两只。血量按本关基础E01的45%/40%且至少8/4，不用旧后期指数曲线。树掉桃/动物掉心，共享地面4个上限；满心也消耗回血物但不溢出上限，寿命/移动购物冻结。

金币首波×1.25，后波按stageCoinMultiplier抵消密度增益（叠收入）小数余数累积，value掉落/拾取/回收，节点≤128、满池合并。基础吸附240，小刘×1.15，上限360；飘字纯+N。召唤物/中立无金币或充能；小Boss赏金在波末军饷一次支付。

## v9.7触屏输入修复与手感

Cocos3.8.8 UI PointerEventDispatcher先于全局input分发；全屏Canvas已有audioTouch监听时会吞掉触摸，导致input.on的摇杆收不到真实事件。摇杆改为同Canvas的TOUCH_START/MOVE/END/CANCEL捕获监听（与音频首触共存），不再依赖全局触摸。回调仍按合法激活区/首触点ID/状态保护；技能手指不抢摇杆。销毁时对称off，不能恢复只有input.on的错误路线。真实微信工具同触点先复现不动、捕获路由后约.455移动/.3可视指位与实际位移已验证；不当iPhone延迟/FPS实测。

死区6%、80%行程全速、.7幂响应；独立stickThumb按真实指位绘制，clearTouch同帧清移动与可视头位，不加转向/移动惯性，最大速度/碰撞/击退不变。
