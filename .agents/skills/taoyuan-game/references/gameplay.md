# 玩法与状态边界 v8

正式流程与完整规则见[分关挑战](stage-challenge-proposal.md)，精确内容与数值见stage-data.ts和生成目录。不要把campaign.ts的旧热身/升级函数或chronicles的七章兼容曲线当作正式入口。

## 流程与生存

选择小刘/小关/小张→个人已开放关卡→基础武器（已成长则个人固定本命）与共享已解锁技能→直接战斗（28币保留到波末）→五波45/45/小Boss全灭/60秒与大Boss→单关结算。第3波小Boss全灭立即结束，其他普通波到时购物；第5波杀Boss才胜利。普通兵与在途攻击保留到波间/入Boss，购物冻结、BGM持续，出店准备1.2秒；只小Boss死回1心，其他波不回满。整关死亡重试全新构筑，不带失败所得，也不回第一关。关间不继承任何当局装备、被动、增益、金币、充能。

基础小刘5心/300速度/1.0武器频率，小关5心/345/.85，小张6心/270/1.15；每英雄首通每关另+1心、骑乘基础速度+30%。一次有效伤害扣1心，碰撞和受击无敌一致；有个人首通永久生命增长；无自然回血或经验/等级。所有回血上限/结算空心/存档校验读取heroMaxHearts，不能把小张裁成5。

真实受击使用hurtTime=1.2+道具加成，扣心/闪红/击退/音效；protectionTime用于开店后保护，不能闪红或复用旧扣血。大Boss致死命中置victoryPending后阻断同帧敌伤。

## 操作与时钟

左下固定摇杆：距左165/底160、底座96、头36、激活140、最大位移60、12%死区、模拟量响应0.8幂。电脑方向键/WASD，Space/E技能；斜向等速、松手停止、失焦清输入。摇杆只接首个合法触点，技能手指不抢占；购物隐藏战斗HUD，倒数可提前按住但不提前模拟。右下技能与摇杆水平对齐。

仅battle/非暂停/非后台/非演武配置时推进模拟，每帧最多.08秒，拆1/120秒；购物、准备、后台不计波时长与成绩。run.wave=2是兼容字段，正式波次读stageWave，不能由wave===1走旧15秒热身。

## 地图、出生与掉落

地图宽高各视野1.5倍、镜头夹紧、HUD固定。六关主题地表色/边缘小旗、浅河岸、阔叶、星纹均静态绘制，不挡人物、不制造额外碰撞。仍以草地小花为主。

普通/骑兵/Boss出生.9/1.1/1.5秒，前32%只标记，其后真实形象渐显；出生期无伤害/攻击。复用先清旧Sprite与身份，首次显形到完成不换兵种。可见且出生完成才记正式图鉴发现；屏外/后台排队/演武不记。

小桃树约82×86、首次8–12秒、之后40–60秒、最多两棵/寿命35秒；动物鸡兔猪首次25–40秒，之后45–65秒，最多两只。血量按本关基础E01的45%/40%且至少8/4，不用旧后期指数曲线。树掉桃/动物掉心，共享地面4个上限；满心也消耗回血物但不溢出上限，寿命/移动购物冻结。

金币基础×1.25（叠收入）小数余数累积，value掉落/拾取/回收，节点≤128、满池合并。基础吸附240，小刘×1.15，上限360；飘字纯+N。召唤物/中立无金币或充能；小Boss赏金在波末军饷一次支付。

## 敌军与性能

固定关卡HP倍率1/1.14/1.30/1.48/1.67/1.88，波内.8/.95/1/1.1/1.1；投入按成本预算，普通兵双上限从22成本/26人至52成本/56人，最多80敌方实体。按波引入新兵、限制远程/骑兵/器械与军医旗手，不随玩家装备动态抬血，不缩短预告/加快弹速。Boss保持当前动作/特效池，吕布小Boss只用冲锋与回旋。

普通兵硬直间隔≥.28秒，骑兵≥.5秒；机关枪硬直.018秒，常规.07秒，不能让高频受击闪白锁死移动。共享280粒子、160友弹、80敌弹、6危险区；装饰降档不删除真实伤害。

演武场独立：无限生命、全36武器四阶/全12技能、任意40兵/7名将数量；免充能、手动出兵、清场/重置，绝不写正式通关/发现。详情见training。

E01黄巾农兵现为可读近战样板：0.48秒锁向抬手，挥下判120°/70距离一次1心，0.30秒出手与收招，周期1.3秒。E01普通本体取消接触伤害，仅真实挥击可伤人；其他兵/Boss规则保持。镰刀/锄头与四朝向用已有动作帧，详见art-ui-audio的v8.5。

## v8.6敌军招式伤害

所有正式命名兵种、Boss与随从取消被动碰撞扣心，伤害只来自可见挥击、冲锋扫掠、弹体或危险区；旗手/军医贴身不攻击。近战攻击开始锁向，短前摇按enemy-actions设下限，实际碰撞与动作共用该时钟。普通E01 .48秒释放与1.3秒周期保持。未命名旧测试/兼容敌人仍走旧行为，不把它当正式出兵路径。详见[动作契约](enemy-actions.md)。
