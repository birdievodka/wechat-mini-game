# 玩法与状态边界

正式入口以 `GameBootstrap.ts` 的 `showMainMenu/startWave/finishWave/resumeSupply/update/simulate` 为准；精确参数见生成的 `balance-tables.md`。

## 正式循环

1. 首页选刘备、关羽或张飞，点“开始”，直接持该英雄默认白色武器进入热身。卡片只展示姓名和简短定位，不显示属性。
2. 热身20秒，起始3步兵，1.6秒尝试增兵，上限12；步兵生命6。击杀给经验和落地金币。
3. 结束先回收金币、奖励30金币、回满五心，打开 `supplyMode=departure` 热身商店。此时仍 `wave=1`，无尽时间为0，不显示“难度升级”。
4. 初次货架两把武器（一把保证同款）、一件适配被动。可全买、刷新再买、合成和出售，也可不买直接继续。没有领取或自动复制武器。
5. 点“进入第1波”后才进入正式战斗（兼容字段wave=2），原地计时、提示“难度升级”。角色、镜头和装备不重置。
6. 正式三波，每波30秒；30/60秒打开普通补给，90秒完成第三波后进入张角战前补给，可选天命或普通货架。热身不算其中一波。
7. 点击“挑战张角”后保留存活旧敌兵、行动/攻击阶段和敌方弹幕，生成唯一张角加入战场；保留英雄位置/装备/地图/中立物。停止普通兵补刷和定时商店，没有限时熬过首领的自动胜利。
8. 击败张角立即通关结算，开心立绘和“胜”章；本版没有第四波或其他首领。五心耗尽仍失败哭泣。通关最佳保存到独立taoyuan-clear-best，取更短用时；旧无尽纪录不混用。

热身购物不增加正式波数、也不自动给武器。完成波数/首领标志独立保存在wavesCleared/bossEncounter；继续与通关回调幂等。当前完整流程详见[首章通关规则](chapter-zhangjiao.md)。

## 操作与计时

- 手机使用左下固定方向摇杆，中心距视野左边165、底边160游戏单位，底座半径96、摇杆头半径36、激活半径140、最大位移60，12%中心死区。按底座偏侧立即移动，拖出底座仍限速；松手停止并归中，底座保留。战场中央不生成摇杆。
- 摇杆只接管首个合法触点；技能手指不夺取/释放移动，暂停/后台/购物清输入并隐藏底座，恢复后原位显示。准备倒数可提前按住摇杆，冻结结束后才响应移动，不提前推进战斗。
- 电脑方向键/WASD，斜向归一化；松鼠标不清键盘，失焦/后台清输入。Space或E用角色技能。
- 自动攻击按每个武器实例的射程与冷却独立索敌。普通攻击优先敌军，缺血时中立目标也可能进入优先选择。
- 右下按钮为角色专属技能，有冷却，中心与左下摇杆共用同一高度（距底160游戏单位）；道具全被动，不添加主动道具按钮。
- 仅 `phase=battle && !paused` 推进模拟；每帧最多0.08秒，拆成1/120秒子步进。不要用墙上时间补算离线战斗。
- 购物释放移动输入、冻结完整战场，背景音乐持续播放并推进音乐时钟；切后台暂停，回到商店接续。继续后1.2秒准备倒数及1.2秒独立免伤，8秒减缓新敌投入；倒数不计成绩。

## 生存与成长

- 正式模式固定5心，敌方攻击一次1心。没有上限成长、护甲减伤、自然再生、吸血或升级回血。
- 真受伤：扣心、闪红、扣血数字、反向击退、命中音，以及 `hurtTime=1.2+道具加成` 受击无敌。
- 过关/补给免伤用 `protectionTime`，与 `hurtTime`、技能的 `skillProtected` 分离。保护不闪红、不显示旧伤害、不触发受击加速。菜单/重开清掉两类计时及视觉。
- 经验继续自动到账，但不显示经验条和等级。升级需求 `10+5*(等级−1)`，后台每级伤害+3个百分点，最多30级；满级每10经验换1金币。当前不弹升级三选一。
- 受击闪白、实际硬直、击退分开。普通兵硬直间隔至少0.28秒，骑兵0.5秒；机关枪硬直0.018秒，常规普通兵0.07秒。不能再让高频闪白持续阻止移动。

## 地图、中立目标与掉落

- 世界宽、高各为当前视野1.5倍，面积2.25倍；使用 `resizeWorld/WORLD`，不是固定4000×2250。镜头跟随并夹紧，HUD不随世界平移。
- 草地和稀疏小花为主，无大石头、推车、常驻大桃树等遮挡物。
- 地图内合法随机位置出兵，先出生预告：普通兵0.9秒、骑兵1.1秒、首领1.5秒。预告期不受伤、不攻击，技能也不能绕过。
- 小桃树约82×86，首次8–12秒，之后40–60秒尝试；最多两棵，寿命35秒。静止、受击轻晃、不伤玩家，生命至少8或同期步兵45%。
- 鸡/兔/猪在正式波次出现，最多两只；首次正式战斗25–40秒，之后45–65秒尝试，走动并受惊逃跑。动物和树不算敌军击杀，不给经验/金币。
- 树掉1桃，动物掉1心，共用最多4个地面回血物的预算。**满血也拾取并消耗，但不超过五心**。拾取延迟0.25秒，基础吸附90可增至180；基础寿命20秒可延到40。购物冻结寿命，金币回收不扫回血物。
- 金币按基础掉落及收入余数生成，落地延迟后吸附；基础240，刘备额外15%，上限360。飘字只显示“+1”，左上显示总数。

## 英雄专属技能

技能伤害基数为当前所有武器的 `weaponDps` 之和，再乘 `1+skillDamage`，不是只用初始武器或面板首件伤害。冷却为原始冷却除以 `1+skillHaste`；F08上限使有效冷却最低原始55%。购物、后台和准备倒数冻结冷却。

| 英雄 / 技能 | 当前效果 |
| --- | --- |
| 刘备·以德服人 | 30秒冷却，240范围圆周打击，伤害系数0.8，最多12目标，击退参数350；0.35秒技能免伤，2秒移动加速15%，清除150范围内敌方箭 |
| 关羽·横扫千军 | 26秒冷却，520距离、约75度扇区，系数1.4，最多12目标，击退参数100；在最近三个候选敌人的方向里选择覆盖人数较多的方向，不要求玩家手动瞄准 |
| 张飞·桃园狮吼 | 32秒冷却，260范围、系数1.1，最多16目标，击退参数350，清除150内敌方箭；另在最多两个存活候选敌人的位置延迟0.35秒开85半径桃花，伤害为技能基数35% |

技能只打已完成出生的敌军，不打动物/桃树。张飞两朵追加桃花共享已命中集合，同敌最多吃一次追加。技能主命中使用初始武器ID进入 `hitEnemy`，还会受到其伤害修正路径影响；表中参数不是最终保证伤害/位移。普通敌军可被短暂打断，首领和正在攻击的骑兵豁免该打断。技能表现约0.72–0.8秒，详见 `combat-effects.md`；表现不新增伤害段或主动道具按钮。

## 敌人职责与曲线

步兵封路，弓兵迫使走位，骑兵穿过清怪线逼迫变向，张角用雷阵压缩安全区。小兵无血条，首领有独立血条。

- 战斗生命倍率 `1.28^min(m,8)*1.35^max(m−8,0)`。基础步兵24、弓兵22、骑兵110、张角4200；首个张角在90秒按当时倍率生成约6082生命（以实际取整为准）。只在出生时计算，不追溯补血，不按玩家装备同步抬生命。
- 弓兵比例25%渐增至40%，骑兵10%渐增至30%。出兵预算 `min(7.5,2.5*1.16^m)`，权重步兵1、弓兵1.25、骑兵2.5、首领20。上限80敌，满员丢弃新增，不积攒爆发队列。
- 弓兵0.18秒出箭、没有瞄准线；已开始的射击不因受击反复重置。最多四弓兵同时进入攻击动作。
- 骑兵追到260内才蓄势0.45秒，锁向冲锋540速度、0.62秒，收招0.4秒、冷却2.2秒；最多两只同时攻击。没有路径/范围线，保留姿势与尘土。常态受35%击退，冲锋中10%。
- 张角交替定点雷与三才阵，预警位置不追人；0.85秒预警，后续圈错开0.16秒。普通冷却2.6秒，半血后2秒；一次1心，预警和余光不重复结算。仅受6%击退，普通命中不打断施法。

数值是调试基准，不是已经证实的真人生存分布。改平衡同时核算输出、控场、射程、敌兵组合与经济，不用一场试玩证明整体难度。
