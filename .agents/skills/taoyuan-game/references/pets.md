# 三英雄灵宠与首通武器奖励（已实施）

用户已批准art/concepts/hero-pets/design.png并授权一起实现武器解锁提案。当前与无尽/设置分支合并运行，版本以survival.SURVIVAL_VERSION为准，不覆盖另一任务的版本号。完整实现与验收见[本版说明](../../../../docs/pets-and-unlocks-v917.md)。

## 灵宠

该英雄有效连续首通S05后自动获得；小刘桃桃兔、小关小青蛟、小张橘虎崽。不同英雄分别推进，不扩散成长。旧有效S05记录直接派生，不额外刷。每名英雄1只、不占六槽/通用/冲刺技能位、无独立操作或喂养/升级；敌军从不索敌/碰撞宠物，宠物不挡弹、不吸引仇恨、不回血。

- 桃桃兔：1.2秒/42伤/400射程，640速度桃核，命中后在140内向另一敌人弹射一次25伤，同弹同敌一次；偏好远程兵，实体弹体可被前方其他敌人截中。与英雄普通弹体共享160活跃总额，自己最多2颗。
- 小青蛟：1.5秒/54伤，.18秒起手后165半径140°横扫，最近6人上限，每次每敌只判一次。
- 橘虎崽：1.8秒，.16秒起跳/.42秒落地，扑距≤220；主目标60，落点70内附伤24，主目标不重复吃附伤、总目标≤5。主普通兵眩晕.25秒，同敌3秒内不重复；Boss/精英/召唤不晕。
- 伤害独立，不继承玩家力量/暴击/攻速/技能伤害/分裂/弹射/本命三连/桃花连爆。正式重打S01–06倍率.4/.5/.65/.8/.9/1；演武按备战所选关卡使用同一倍率，无尽使用满强度。击杀真实普通兵仍正常金币和15击杀充能；首领/精英/中立/召唤不计。
- 孟获兽群实际冲锋无敌同样过滤宠物伤害/控制；蓄势/收招恢复可打。玩家免伤/受击流程不因宠物改变。

PetRuntime只模拟，不建引擎对象/读取战斗RNG/墙钟，索敌10Hz。跟随约侧后90、正常英雄速度+60（上限580），落后160外追赶720；落后320且已屏外才回位。攻击锁定期间独立动作，虎扑落点固定。暂停/购物/后台/准备/演武配置冻结；重试/清场/退出清弹、引用与姿态。

## 表现与资源

art/runtime-pets保留内置image_gen批准版来源、完整提示词和确定性pack-pet-art.cjs。pets/pets.png为512²/1MiB RGBA、15真实alpha帧：每物种常态/眨眼/小跑A/B/攻击；素材PNG约286KiB。pet-art.ensureSheets从微信pets分包加载原图。成长已得才预取菜单，进入战斗和初得结算检查就绪；切到无宠英雄菜单先清Sprite引用再释放。没有首屏额外依赖或整图海报入包。

PetView每处1个Sprite，战斗地面影子/桃核/青刃/肉掌落地均复用原friendlyGroundFx/fx，无逐宠Graphics、刚体或独立粒子系统。真实命中进入hitEnemy但带petSource，绕过武器增益，保留敌军盾/藤甲等防御。菜单/胜利用动态PetView，失败用闭眼姿态。菜单/胜利宠物摆在英雄左侧，避免被右侧地图/纸卡遮挡。

## 首通武器

资格仍全账号共享，来源改每关公共1件＋每英雄个人首通1件，S01个人本命另作为成长进阶并加入共享商店资格。STAGES.firstClear.weapons仅公共表，HERO_WEAPON_REWARDS为个人表；结算显示实际两件战利品并标公共/某英雄首通，本命在成长区显示。已拥有不重复标新。初始仍三基础；高级解锁只进商店，不扩初始武器选择或自动装备。

profile.version升2、原键保持，legacyWeapons保存v1验证过的通关记录按冻结LEGACY_WEAPON_REWARDS产生的旧资格。新表与旧资格合并去重；迁移不替其他英雄写通关、不截断旧高心记录；二次读取幂等。新档一英雄六关16把、两英雄23把、三英雄30把；六预留仍在36总图鉴匿名剪影，老已得不回收。武器表、归属、迁移测试及当前首通显示见实现说明。
