# 已知描述与实现差异

这是创建 skill 时基于当前调用链发现的具体差异，**没有在规范整理任务里顺手改游戏**。后续涉及这些机制时复核，修复后删除或改写对应条目，同时补行为验证；不能把它们误写成已完成能力。

| 项目 | 当前事实 | 检查位置/影响 |
| --- | --- | --- |
| B06临危不乱 | 描述/属性可把加速时长算到2.5秒，但移动逻辑用剩余 `hurtTime` 与 `max(0,1.2−hurtDuration)` 判断，没有独立加速计时 | 实际加速时长受受击无敌总时长约1.2–1.8秒限制 |
| C05货比三家 | 刷新优惠对递减后的数值先floor，中间重复件数不一定即时再便宜1金币 | 例如第二件可能与第一件同价；目录文案不应被解读成每件固定−1 |
| 命中停帧 | `weaponFreeze` 被赋值和递减，但未用于阻止模拟或武器推进 | 目前有命中形变/闪白/击退/音效/小幅震动，不能声称实际已停帧 |
| 小桃树静止 | 单体更新不移动树，但软分离循环仍对所有活实体执行 | 挤压场景可能轻推树；单测 `updateAnimal` 不代表完整战场绝对静止 |
| 桃/心掉落数量 | `dropHeart` 在已有4个活回血物时直接返回 | “击倒掉一个”受公共预算限制，不是所有情况下保证落地 |
| 独立音色 | 后六把现代/修仙武器映射复用原六武器音色 | 11武器不等于12套独立音频；实际声源11个 |
| 旧商店/升级 | 旧 `buyItem/rollShop/availableUpgrades`、旧UI与部分测试还在 | 当前入口不调用，不要拿其三件上限、锁定、价格或升级加生命作为现行规则 |

当目录和实装冲突时，分别写清设计承诺、实际行为和本次是否修复；不要仅修改技能目录，掩盖代码仍未生效的问题。
