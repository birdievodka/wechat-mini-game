这是随代码维护的项目约定。仓库根目录包含 `assets/scripts/GameBootstrap.ts`；通过用户级软链接调用时，先定位实际仓库，不在 skill 安装目录构建游戏。

## 当前主线 v10.0（全量战斗特效）

- 正式名桃园小英雄；搞笑三国、小脚豆少年Q版。仅小刘/liubei、小关/guanyu、小张/zhangfei可见；赵云/孔明暂隐藏，资产/ID/旧存档保留。

- 开局不进商店，直接持初始所选基础武器／个人已进阶本命战斗，首次购物在45秒后。黄巾第三波改三只冲锋精英，每只2400血，三只全部击败立即结束；只发一次回血/波末赏金，精英不算15击杀。
- 无热身，1/2波45秒、第4波60秒，第3波小Boss全灭立即结束，第5波击败大Boss。Boss进场不清普通兵/在途攻击，持续援军。商店无限时、BGM续播，出店1.2秒倒数。
- 每关新构筑：满心（基础心数＋个人首通关数）、28币、1把白I本命、1个已解锁技能就绪；下一关先回备战，装备/品质/被动/天命/增益/钱/充能全部重置。失败再战本关也全新构筑；首页无继续选择，不自动读旧快照。

- 备战上方动态少年与个人关卡卡，下方3纯头像＋初始武器方钮＋技能圆钮，开始挑战水平居中；无选择英雄大标题/属性墙。未成长时草鞋/扁担/杀猪尖刀任选；首通黄巾后改自己固定白I本命（小刘双股剑、小关青龙刀、小张丈八蛇矛），武器钮打开成长路线。其他已解锁武器仍只进商店，本命资格不扩散给其他英雄。
- 36武器总表（新档30可获得/6预留）/60被动/9天命/12通用技能；初始3武器、24被动、3技能，武器按公共＋英雄个人首通发共享资格。高级武器商店付费购买，不能设为初始。四卡可全买，买后售罄保留，刷新5/8/11/14/17/20封顶，每店重置；C05保留首刷优惠。升阶收差价和20%加工费，替换净额确认/真实投资退款。

## 执行方式

1. 遵循当前需求与授权范围。“先出设计稿”止于设计，确认实现后再写代码。当前用户指令优先；实装与设计不一致时注明差异。
2. 查当前入口真实调用：战斗为 `GameBootstrap.ts`，现行商店为 `survival.ts`。`campaign.ts/CampaignView.ts` 保留旧商店和升级函数，不能误当现行流程。
3. 修改实现并做有行为意义的验证。正式试玩只用正常输入，不修改生命、金币、计时、敌兵或阶段；工程测试夹具与实际试玩分开报告。
4. **同一任务同步 skill**：更新受影响的人工参考，运行 `npm run skill:sync` 生成目录，再执行 `npm run skill:check`。`npm run check` 同时检查同步状态。
5. 按修改范围执行测试、类型检查、构建；交付明确是否已加载微信端，不把模拟器检查说成手机验证。

生成器不会审批新规则，也不会自动重写人工说明。不要只刷新目录便宣称全部参考已更新；目录描述不等于最终运行时效果。发现实现差异先记录，不在无关任务中擅自改玩法。
