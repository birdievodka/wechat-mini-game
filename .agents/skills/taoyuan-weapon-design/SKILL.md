# 桃园小英雄 · 兵器设计

## 先查这件兵器处在哪个版本

- **现行机制**查[代码生成的兵器谱](../taoyuan-game/references/weapon-catalog.md)。v10.15 玩家可见 33 件，新档可得 30 件，另有 3 件预留。突突枪、霰弹枪、火箭筒已退出玩家目录。需要调整获取途径时，核对[首通奖励与旧档映射](../taoyuan-game/references/weapon-evolution.md)。
- **重制目标**查[33 件兵器逐件成长稿](../../../docs/weapon-system-redesign.md)。按兵器名找到对应行，读完白至红四档以及最后一列的反馈和代价。答复某机制能否在游戏中体验时，以实际攻击、命中和回收路径为准。部分武器已有相似行为，先确认缺的是判定、表现还是说明。
- **重制规则与样板**查[武器重制规则](../../../docs/redesign/weapons.md)。逐件主轮廓、触发去重与终止条件、草鞋／手戟／贯石弩／火油壶的原型起测值都在这里。与现行兵器谱对照后再落地。
- **已接入样板**见[首批实装](../../../docs/redesign/implementation.md)。`stage-v11.0-handcrafted` 的草鞋第三跳、手戟折返、贯石弩穿阵和火油壶火线走正式攻击路径，`test-armory-redesign.cjs` 检查实际命中与清理。其他刀兵的重制行为仍以逐件设计稿为目标。

## 设计一件值得买的武器

1. 写出玩家能做的事。例如「横移让回程手戟横切追兵」「把长队引进贯石弩的射线」。同时指出失手机会和短板，例如重弩绞弦时被侧翼贴身。搞笑三国的兵器要看得出材质和用法，草鞋凭鞋底回弹和拍脸声也能打出分量。
2. 给四档各写一条**在战场上能看见的变化**。

   | 品级 | 要回答的问题 | 手戟的提案例子 |
   | --- | --- | --- |
   | 白 I | 第一件拿到手有什么招牌动作？ | 去时一下，回时一下。 |
   | 蓝 II | 哪个使用难点变得好掌握？ | 折返点更清楚，回程更快。 |
   | 紫 III | 玩家现在值得走到哪里？ | 戟回到英雄当前位置，横移能扫出第二条路线。 |
   | 红 IV | 做对什么才打出最精彩的一击？ | 回程切过三名不同敌人，接住立刻补掷。补掷不能再触发补掷。 |

3. 写商店里的升级预告，让人买前就能想象效果。「回到投出点 → 回到你手上」比「回程强化」更具体。另列实质改变的伤害、间隔或覆盖。满六槽替换时，同时说明失去的打法与退款。保留六槽、自动攻击和现有操作。本命三连跟随英雄成长及装备标记，设计同名商品时单列其普通版本。

## 把打击感落在真实接触上

按起手、运动、命中、收招描述主体，并标清哪一刻判伤。贯石弩可绞弦蓄势、沿直线出箭，击穿前两人时各给一声短响，第三次穿透才在后排打出碎石和低音。只射中一人就只演第一拍。给空挥、单体、多目标分别规定反馈，标清同敌命中上限、首领抗性和追加攻击的终止条件。

六槽同屏时，优先保住兵器轮廓、真实落点和敌军预警。五雷符沿敌群跳，雷霆万钧多柱同拍落下，两者关掉声音也应一眼可辨。普通兵器不消耗主动技能充能。重击可在表现层短暂停住武器，摇杆、英雄移动和模拟时钟继续响应。提案中的 35–55 毫秒姿态停顿、80 毫秒同类视觉合并均为原型起测值。进入表现实现时复用共享绘制、粒子池与六声道优先级，按[战斗特效 skill](../cocos-game-vfx/SKILL.md)核对实机尺寸与真实命中。

## 交付与验收

- **设计交付**写明当前行为、四档变化、购买理由、占优与吃亏的场景，再给出一个能验证差异的走位。首批样板为草鞋（拍击）、手戟（折返）、贯石弩（穿阵）、火油壶（留场）。
- **原型对照**用同英雄、品级和投入测 30 秒对单、8 人纵列、12 人包围、移动首领。记录伤害之外的实际收益，例如回程多切几人、赶走几名追兵、留出几步退路。紫手戟要比较站桩与横移两种回收路径。原稿约 20% 的弱项差距是调参目标，试玩后再定。
- **获准实现后**在普通、无尽、演武验证同一招式，检查六槽并发和敌方危险区可读性，真机长测覆盖至少 10 分钟及反复进出商店。分别记录行为用例、帧耗时和资源趋势，注明设备和未测范围。
- 后续改变单件设计时，同步修改[逐件成长稿](../../../docs/weapon-system-redesign.md)的相应行。机制实装后更新项目人工参考，在仓库根目录执行 `npm run skill:sync` 和 `npm run skill:check`。项目共用的设计原则有变化时，再更新本入口。
