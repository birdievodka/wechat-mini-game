## 首页

删除顶部中央“选择英雄”文字和整块墨色标题底板，保留左上正式Logo。中部继续分层动态英雄、姓名；下方五个纯头像和列表右侧小技能图标。底部开始按钮居中，图鉴为次级入口，不新增属性、说明段落、测试或选武器。

## 暂停及控件

将自绘暂停键移至左上状态栏右侧，与状态栏垂直居中，保持约12～16逻辑单位间距。按钮改为玉绿圆底、细浅金边、米白双竖线；建议可见直径48、触摸区域至少64。微信右上原生胶囊保持系统控制，游戏控件避让。

战斗中仍左下固定摇杆、右下所选通用技能，二者水平对齐。技能图标和充能数值沿当前选择，不能把草鞋武器图当通用技能图；HUD稿以G03就绪为示例。

购物打开后隐藏底层战斗HUD、暂停键、摇杆、技能键与旧武器HUD，冻结的战场仍可见；结束购物恢复一次。BGM继续，后台仍暂停。避免底层按钮穿透及两个武器栏叠加。

## 商店布局

| 区域 | 提议 |
| --- | --- |
| 顶栏 | 左侧标题“桃园补给”及短提示“可购买多件”；右侧铜钱图标＋余额，作为只读信息，不做按钮，不重复显示余额 |
| 商品区 | 三卡等宽等高，品质、插画、名称、核心属性、购买按钮各自对齐；默认压缩为两行核心信息，完整机制保留在详情 |
| 装备区 | 统一浅边框条：武器数量、六个武器槽、右端“道具 N”入口；点击武器仍管理、出售、合成或替换 |
| 操作区 | 最底部单独一行，左刷新（标当前费用），右朱红“继续战斗”；保持同一基线，中央留白，移除底部重复说明段落 |

保留三卡可全部购买、每次刷新涨价、六武器位、被动不限槽、卖合替换和已购禁用态。升阶仍显示旧品质→新品质，金币不足仍明确禁用。天命补给与普通补给的切换放在标题旁的小型切换控件，避免挤占底部主操作。

## 布局与实现边界

- 以实际安全矩形计算，不硬抄概念图像素。建议以1334×750逻辑画面，弹窗宽不超过1140、高约650，内边距20～24；商品间距约22～24。顶栏、商品、装备、操作四行独立分配高度。
- 所有卡片购买按钮至少48高；底部主操作约56高。小横屏先压装饰与卡片图标，不缩小按钮至难点；适配1334×750及更宽屏、刘海和Home安全区。
- 延用棕色粗描边、纸色字、玉绿底和朱红主按钮，主要依靠间距与层级改善拥挤；不增加大面积金属装饰或新的纹理发射器。
- 稿件由内置imagegen生成，是评审概念，不是微信截图或可直接使用的UI整图。兵种、技能图标、数值、场景装饰以当前代码与素材为准；商店稿边角出现的石头、额外装饰不加入实际草地地图。
- 实现保持英雄现有亮相/眨眼，弹窗真实半透明，战斗伤害/购物价格/存档与地图规则不因布局变更而调整。核对打开/关闭商店、按钮穿透、金币购买后更新、六槽满载、长说明、天命页和后台恢复。

原始问题截图保存在[参考截图](reference-shop.png)。只保留这一版已确认布局，不把未采用的生成中间图加入游戏包。
